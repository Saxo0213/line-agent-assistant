# v1.0.311 — changes since v1.0.310

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE-Agent-Assistant-1.0.311-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.311.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。`latest.yml` 與 `.blockmap` 供 App 內自動更新使用；已安裝 v1.0.310 的使用者可直接在右下角提示選擇「更新」。

相較於上一個公開版本 [v1.0.310](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.310)：

- **外部 MCP 傳送與排程管理**：loopback MCP 端點不使用 token；只連接你信任的本機 MCP 客戶端。外部 MCP 可查詢 Agent 與主要管理者帳號資料，LINE 訊息則一律由 Agent 帳號送出。
- **外部排程**：外部客戶端可透過 MCP 建立、列出、修改與刪除排程；到點後由 App 內建 Agent 執行。每次外部呼叫都保留獨立 audit ID。
- **內建 Agent 的相簿目錄**：內建 Agent 可使用相簿目錄工具查閱 LINE 相簿。
- **停用記事本**：App、內部與外部 MCP 都不再提供記事本功能或工具；既有封存記事資料保留。
- 本程式仍為非官方專案，與 LINE 無隸屬、背書或贊助關係。

## English

Windows x64 release. Download `LINE-Agent-Assistant-1.0.311-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.311.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`. `latest.yml` and the `.blockmap` are used by the in-app updater; if v1.0.310 is installed, choose **Update** in the bottom-right prompt.

Changes since the previous public release, [v1.0.310](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.310):

- **External MCP sending and schedule management:** the loopback MCP endpoint has no token; connect only MCP clients you trust on this computer. External MCP can query both Agent and primary administrator account data, while LINE messages are always sent from the Agent account.
- **External schedules:** clients can create, list, update, and delete schedules through MCP. The built-in Agent runs them when due, and each external request retains a separate audit ID.
- **Album catalogs for the built-in Agent:** the built-in Agent can use album catalog tools to browse LINE albums.
- **Notes disabled:** the app and internal and external MCP no longer expose Notes features or tools. Existing archived Notes data is retained.
- This remains an unofficial project and is not affiliated with, endorsed by, or sponsored by LINE or its affiliates.

## 日本語

Windows x64 版です。**Assets** から `LINE-Agent-Assistant-1.0.311-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.311.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。`latest.yml` と `.blockmap` はアプリ内の自動更新で使用します。v1.0.310 をお使いの場合は、右下の通知で「更新」を選択できます。

前回の公開版 [v1.0.310](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.310) からの変更点：

- **外部 MCP の送信とスケジュール管理**：loopback MCP エンドポイントに token 認証はありません。この PC で信頼できる MCP クライアントのみ接続してください。外部 MCP から Agent と主管理者の両アカウントのデータを照会できます。LINE メッセージは常に Agent アカウントから送信されます。
- **外部スケジュール**：外部クライアントは MCP 経由でスケジュールの作成・一覧表示・変更・削除ができます。実行時にはアプリ内蔵 Agent が処理し、外部からの各呼び出しには個別の audit ID が保持されます。
- **組み込み Agent のアルバム一覧**：組み込み Agent がアルバム一覧ツールで LINE のアルバムを参照できます。
- **Notes の無効化**：アプリと内部・外部 MCP では Notes 機能やツールを利用できません。既存の Notes アーカイブデータは保持されます。
- 本アプリは引き続き非公式プロジェクトであり、LINE およびその関連会社とは提携・承認・支援関係にありません。

## 한국어

Windows x64 버전입니다. **Assets**에서 `LINE-Agent-Assistant-1.0.311-Setup-x64.exe`를 다운로드하세요. `LINE-Agent-Assistant-1.0.311.zip`은 포터블 버전입니다. SHA-256 값은 `SHA256SUMS.txt`에 있습니다. `latest.yml`과 `.blockmap`은 앱 내 자동 업데이트에 사용됩니다. v1.0.310을 사용 중이면 오른쪽 아래 알림에서 '업데이트'를 선택하면 됩니다.

이전 공개 버전 [v1.0.310](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.310) 이후 변경 사항:

- **외부 MCP 전송 및 일정 관리**: loopback MCP 엔드포인트에는 token 인증이 없습니다. 이 컴퓨터에서 신뢰하는 MCP 클라이언트만 연결하세요. 외부 MCP는 Agent와 주 관리자 계정의 데이터를 모두 조회할 수 있고, LINE 메시지는 항상 Agent 계정에서 전송됩니다.
- **외부 일정**: 외부 클라이언트는 MCP로 일정을 만들고, 조회하고, 수정하고, 삭제할 수 있습니다. 실행 시점에는 앱 내장 Agent가 처리하며 각 외부 호출에는 별도의 audit ID가 유지됩니다.
- **내장 Agent의 앨범 목록**: 내장 Agent가 앨범 목록 도구로 LINE 앨범을 확인할 수 있습니다.
- **Notes 비활성화**: 앱과 내부 및 외부 MCP에서 Notes 기능이나 도구를 사용할 수 없습니다. 기존 Notes 보관 데이터는 유지됩니다.
- 이 앱은 계속 비공식 프로젝트이며 LINE 및 그 계열사와 제휴, 보증 또는 후원 관계가 없습니다.
