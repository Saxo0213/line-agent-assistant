## 繁體中文

- **聊天室下載位置：** 聊天室標題列的照片按鈕右邊新增齒輪按鈕，打開「下載位置」。固定位置維持不變，可直接開啟；另可為每個聊天室指定一個「額外儲存位置」，附件下載完成後會再複製一份到該資料夾，既有附件在背景補複製。可開啟、更換、停用（已複製的檔案保留）及重試失敗的複製。系統資料夾、附件主資料夾與其他聊天室的工作資料夾不能使用。
- **下載用登入：** 修正下載用 Chrome 啟動後立即結束（結束代碼 0）、狀態停在「啟動中」的問題。原因是另一個 Chrome（例如「從商店安裝擴充功能」開啟的視窗留在背景）仍在使用下載用設定檔。現在啟動前會關閉所有使用 App 專用下載設定檔的 Chrome，商店安裝結束後也會關閉；其他設定檔的 Chrome 不受影響。

## English

- **Chat download location:** A new gear button, to the right of the photo button in the chat header, opens **Download location**. The fixed location does not change and you can open it from there. You can also set one **extra storage location** for each chat: after an attachment downloads, the app copies it to that folder too, and copies the existing attachments in the background. You can open, change or disable it (copied files stay), and retry failed copies. System folders, the main attachment folder and the work folder of another chat cannot be used.
- **Download login:** Fixed a problem where the download Chrome ended right after the start (exit code 0) and the status stayed at "Starting". Another Chrome still used the download profile, for example the window of **Install extension from store** that stayed in the background. Before a start, and after a store install, the app now closes every Chrome that uses its own download profile. Chrome with any other profile is not affected.

## 日本語

- **トークのダウンロード先：** トークのヘッダーで写真ボタンの右に歯車ボタンを追加し、「ダウンロード先」を開けるようにしました。固定の保存先は変わらず、そこから開けます。さらにトークごとに「追加の保存先」を 1 つ指定でき、添付ファイルのダウンロード後にそのフォルダーへもコピーし、既存の添付ファイルはバックグラウンドでコピーします。開く・変更・無効化（コピー済みのファイルは残ります）・失敗したコピーの再試行ができます。システムフォルダー、添付ファイルのメインフォルダー、他のトークの作業フォルダーは使用できません。
- **ダウンロード用ログイン：** ダウンロード用 Chrome が起動直後に終了し（終了コード 0）、状態が「起動中」のまま止まる問題を修正しました。別の Chrome（例：「ストアから拡張機能をインストール」で開いたウィンドウがバックグラウンドに残ったもの）がダウンロード用プロファイルを使い続けていたことが原因です。起動前とストアからのインストール後に、アプリ専用のダウンロード用プロファイルを使う Chrome をすべて閉じるようにしました。ほかのプロファイルの Chrome には影響しません。

## 한국어

- **채팅 다운로드 위치:** 채팅 헤더의 사진 버튼 오른쪽에 톱니바퀴 버튼을 추가해 '다운로드 위치'를 열 수 있습니다. 고정 위치는 바뀌지 않으며 여기서 열 수 있습니다. 채팅마다 '추가 저장 위치'를 하나 지정할 수 있으며, 첨부 파일 다운로드가 끝나면 그 폴더에도 복사하고 기존 첨부 파일은 백그라운드에서 복사합니다. 열기, 변경, 사용 안 함(복사한 파일은 유지), 실패한 복사 재시도를 할 수 있습니다. 시스템 폴더, 첨부 파일 기본 폴더, 다른 채팅의 작업 폴더는 사용할 수 없습니다.
- **다운로드용 로그인:** 다운로드용 Chrome이 시작 직후 종료되고(종료 코드 0) 상태가 '시작 중'에 멈추던 문제를 수정했습니다. 다른 Chrome(예: '스토어에서 확장 프로그램 설치'로 연 창이 백그라운드에 남은 것)이 다운로드용 프로필을 계속 사용하고 있던 것이 원인입니다. 이제 시작 전과 스토어 설치가 끝난 뒤, 앱 전용 다운로드 프로필을 쓰는 Chrome을 모두 닫습니다. 다른 프로필의 Chrome에는 영향이 없습니다.
