# v1.0.342 — changes since v1.0.323

## 繁體中文

Windows x64 版本。可透過 App「檢查更新」安裝；手動安裝檔與免安裝版請見 GitHub v1.0.342 Release。

- **登入說明：** 「設定 → 系統」的帳號區塊上方新增「登入說明」，說明 Agent 帳號與主要管理者帳號的用途，並列出 4 個登入步驟與完成狀態；尚未完成必要步驟時會自動展開。
- **主要管理者只用監控模式：** 主要管理者不再於 App 內掃 QR 登入，聊天紀錄改由這台電腦的電腦版 LINE 匯入。更換主要管理者改為兩段驗證碼流程，舊管理者會封存保留。
- **下載登入（選用）：** 透過 Google Chrome 與 LINE Chrome 擴充功能 3.7.2，下載主要管理者聊天中的照片與檔案。下載前會先比對訊息內容；帳號以主要管理者送出的一則文字或貼圖確認；App 重新啟動後登入仍保留。「新訊息自動下載」預設關閉。外部監控附件不再使用電腦版 LINE 的登入資訊下載。
- **Agent 回覆帶上被引用的訊息：** 觸發 Agent 的訊息若是回覆，工作會附上被引用訊息的傳送者、時間、內容與已下載的檔案。
- **@提及觸發訊息規則：** 訊息轉發規則可依 @主要管理者、指定成員或 @all 觸發，動作可選轉發、桌面通知或交給 Agent 處理。
- **收回訊息：** 會記錄訊息被收回的時間，Agent 讀取時可取得已收回或已刪除訊息的原文；也會套用 LINE 的收回操作。
- **排程轉發：** 不再等待外部監控照片；無法轉發的附件顯示為 `[圖片]`、`[檔案]`。
- **聊天畫面：** 傳送訊息與捲到底部時，會載入尚未載入的新訊息並置底。
- **其他修正：** 登入後才加入的聊天室可讀取名稱與成員；群組附件路徑與未命名圖片的檔名修正；Agent 帳號自己的附件不再被標成外部監控；Windows 登出或關機時內建 PostgreSQL 快速停止；App 視窗新增右鍵編輯選單。

## English

Windows x64 release. Install through **Check for updates** in the app; the installer and portable build are available from the GitHub v1.0.342 release.

- **Login guide:** **Settings → System** has a **Login guide** above the account section. It explains the roles of the Agent account and the primary administrator account and lists the four login steps with their status. It opens automatically while a required step is not done.
- **Primary administrator uses monitoring only:** The primary administrator no longer logs in by QR code inside the app; its chat history is imported from desktop LINE on this PC. Changing the primary administrator now uses a two-code flow, and the former administrator is archived.
- **Download login (optional):** Downloads photos and files from the primary administrator's chats through Google Chrome and the LINE Chrome extension 3.7.2. Messages are compared before each download, the account is confirmed by one text or sticker sent by the primary administrator, and the login survives app restarts. **Download new messages automatically** is off by default. External-monitor attachments are no longer downloaded with desktop LINE's login data.
- **Agent replies include the quoted message:** When the message that triggers the Agent is a reply, the job carries the quoted message's sender, time, content and downloaded files.
- **Message rules on @mentions:** Message-forward rules can trigger on an @mention of the primary administrator, chosen members or @all, with forward, desktop notification or Agent actions.
- **Recalled messages:** The app records when a message is recalled, Agent reads can return the original text of recalled or deleted messages, and LINE unsend operations are applied.
- **Scheduled forwarding:** No longer waits for external-monitor photos; attachments that cannot be forwarded show as `[圖片]` and `[檔案]`.
- **Chat view:** Sending a message or scrolling to the bottom loads newer messages that were not loaded yet and stays at the bottom.
- **Other fixes:** Titles and members of chats joined after login are read; group attachment paths and names of unnamed images are fixed; the Agent account's own attachments are no longer marked as external-monitor rows; the built-in PostgreSQL stops quickly at Windows sign-out or shutdown; app windows have a right-click edit menu.

## 日本語

Windows x64 版です。アプリの「更新を確認」から更新できます。インストーラーとポータブル版は GitHub v1.0.342 リリースから入手できます。

- **ログインの説明：** 「設定 → システム」のアカウント欄の上に「ログインの説明」を追加しました。Agent アカウントとメイン管理者アカウントの用途、4 つのログイン手順と完了状態を表示し、必須手順が未完了のときは自動で開きます。
- **メイン管理者は監視モードのみ：** メイン管理者はアプリ内で QR コードによるログインをしなくなり、トーク履歴はこの PC の LINE（PC 版）から取り込みます。メイン管理者の変更は 2 段階の認証コード方式になり、以前の管理者はアーカイブされます。
- **ダウンロード用ログイン（任意）：** Google Chrome と LINE Chrome 拡張機能 3.7.2 を使い、メイン管理者のトークの写真とファイルをダウンロードします。ダウンロード前にメッセージを照合し、アカウントはメイン管理者が送るテキストまたはスタンプ 1 件で確認します。アプリを再起動してもログインは保持されます。「新しいメッセージを自動でダウンロード」は既定でオフです。外部監視の添付ファイルは LINE（PC 版）のログイン情報でダウンロードしなくなりました。
- **Agent の返信に引用メッセージ：** Agent を起動したメッセージが返信の場合、引用元の送信者、時刻、内容、ダウンロード済みファイルをジョブに渡します。
- **@メンションでメッセージルール：** メッセージ転送ルールを、メイン管理者・指定メンバー・@all へのメンションで起動できます。動作は転送、デスクトップ通知、Agent 処理から選べます。
- **取り消されたメッセージ：** 取り消し時刻を記録し、Agent は取り消し・削除されたメッセージの本文を読み取れます。LINE の取り消し操作も反映します。
- **スケジュール転送：** 外部監視の写真を待たなくなり、転送できない添付ファイルは `[圖片]`、`[檔案]` と表示します。
- **チャット画面：** 送信時や最下部までスクロールしたとき、未読み込みの新しいメッセージを読み込んで最下部に留まります。
- **その他の修正：** ログイン後に参加したチャットの名前とメンバーを取得、グループ添付ファイルのパスと名前のない画像のファイル名を修正、Agent アカウント自身の添付ファイルが外部監視扱いにならないよう修正、Windows のサインアウト・シャットダウン時に内蔵 PostgreSQL を速やかに停止、アプリのウィンドウに右クリック編集メニューを追加。

## 한국어

Windows x64 버전입니다. 앱의 '업데이트 확인'으로 설치할 수 있습니다. 설치 파일과 포터블 빌드는 GitHub v1.0.342 릴리스에서 받을 수 있습니다.

- **로그인 안내:** '설정 → 시스템'의 계정 영역 위에 '로그인 안내'가 추가되었습니다. Agent 계정과 주 관리자 계정의 용도, 4단계 로그인 절차와 완료 상태를 보여 주며, 필수 단계가 끝나지 않았으면 자동으로 펼쳐집니다.
- **주 관리자는 모니터링 모드만 사용:** 주 관리자는 앱에서 QR 코드로 로그인하지 않으며, 대화 기록은 이 PC의 PC 버전 LINE에서 가져옵니다. 주 관리자 변경은 2단계 인증 코드 방식으로 바뀌었고 이전 관리자는 보관됩니다.
- **다운로드용 로그인(선택):** Google Chrome과 LINE Chrome 확장 프로그램 3.7.2로 주 관리자 대화의 사진과 파일을 다운로드합니다. 다운로드 전에 메시지를 대조하고, 계정은 주 관리자가 보낸 텍스트나 스티커 한 개로 확인하며, 앱을 다시 시작해도 로그인이 유지됩니다. '새 메시지 자동 다운로드'는 기본적으로 꺼져 있습니다. 외부 모니터링 첨부 파일은 더 이상 PC 버전 LINE의 로그인 정보로 다운로드하지 않습니다.
- **Agent 답장에 인용 메시지 포함:** Agent를 실행한 메시지가 답장이면 인용된 메시지의 발신자, 시간, 내용, 다운로드된 파일을 작업에 함께 전달합니다.
- **@멘션 메시지 규칙:** 메시지 전달 규칙을 주 관리자, 지정한 멤버 또는 @all 멘션으로 실행할 수 있으며, 동작은 전달, 데스크톱 알림, Agent 처리 중에서 고릅니다.
- **회수된 메시지:** 메시지 회수 시간을 기록하고, Agent가 회수되거나 삭제된 메시지의 원문을 읽을 수 있으며, LINE의 회수 작업도 반영합니다.
- **예약 전달:** 외부 모니터링 사진을 기다리지 않으며, 전달할 수 없는 첨부 파일은 `[圖片]`, `[檔案]`로 표시합니다.
- **채팅 화면:** 메시지를 보내거나 맨 아래로 스크롤하면 아직 불러오지 않은 새 메시지를 불러오고 맨 아래에 머뭅니다.
- **기타 수정:** 로그인 후 참여한 채팅의 이름과 멤버를 읽고, 그룹 첨부 파일 경로와 이름 없는 이미지의 파일 이름을 수정하고, Agent 계정 자신의 첨부 파일이 외부 모니터링으로 표시되지 않도록 하고, Windows 로그아웃·종료 시 내장 PostgreSQL을 빠르게 멈추며, 앱 창에 오른쪽 클릭 편집 메뉴를 추가했습니다.
