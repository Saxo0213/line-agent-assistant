# v1.0.261 — changes since v1.0.260

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE.Agent.Assistant-1.0.261-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.261.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。

相較於上一個公開版本 [v1.0.260](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.260)：

- 修正外部監控已完成同步，設定頁卻仍顯示「尚未同步」的問題，現在會顯示目前使用中監控來源的已完成同步時間。
- 補足確認 LINE 好友資料失敗時的診斷資訊，保留經篩選的失敗類型與上游狀態碼，協助追查原因。
- 本程式仍為非官方專案，與 LINE 無隸屬、背書或贊助關係。

## English

Windows x64 release. Download `LINE.Agent.Assistant-1.0.261-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.261.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`.

Changes since the previous public release, [v1.0.260](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.260):

- Fixed Settings showing “Not synchronized” after the external monitor had completed synchronization. It now displays the completed synchronization time for the monitor source currently in use.
- Added filtered failure types and upstream status codes when checking LINE friend information fails, to help investigate the cause.
- This remains an unofficial project and is not affiliated with, endorsed by, or sponsored by LINE or its affiliates.
