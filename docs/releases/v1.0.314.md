# v1.0.314 — changes since v1.0.312

## 繁體中文

Windows x64 版本。已安裝的使用者可在 App 內「檢查更新」後選擇更新。手動安裝請下載 `LINE-Agent-Assistant-1.0.314-Setup-x64.exe`；免安裝版為 `LINE-Agent-Assistant-1.0.314.zip`。`SHA256SUMS.txt` 提供 SHA-256，`latest.yml` 與 `.blockmap` 供 App 更新使用。

上一個公開版本為 [v1.0.312](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.312)。本版包含本機版 v1.0.313 的功能與本次修正：

- **啟動補訊旗標：** 啟動或恢復監控時，初始補訊只存檔，不觸發 Agent、自動回覆或訊息指令；補訊全部存檔並確認同步進度後，才恢復新訊息監控。分頁、空回應與重送均遵守同一個旗標。
- **系統額度查詢：** 在 LINE 輸入 `/額度` 或 `/quota` 查詢 Codex／Claude 額度，由系統查詢，不使用 MCP 或 AI 任務。Claude 通用額度決定是否可用；模型專用額度另列。
- **額度不足與切換：** 保留額度不足旗標及恢復時間，系統會回報失敗狀況並在有可用替代 Agent 時詢問是否切換。使用者同意後，聊天室後續使用替代 Agent，並重試這次失敗任務；兩者均不可用時會告知現況，不切回仍受限的 Agent。
- **重複失敗通知修正：** 同一任務多次遇到額度限制時，仍能建立切換提示。

## English

Windows x64 release. Installed users can choose **Check for updates** in the app, then update. For manual installation, download `LINE-Agent-Assistant-1.0.314-Setup-x64.exe`; the portable build is `LINE-Agent-Assistant-1.0.314.zip`. SHA-256 hashes are in `SHA256SUMS.txt`. `latest.yml` and `.blockmap` support the in-app updater.

The previous public release is [v1.0.312](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.312). This release includes the local v1.0.313 features and the startup fix:

- **Startup catch-up flag:** Initial messages received after starting or resuming monitoring are stored without triggering Agent tasks, automatic replies, or message commands. Normal monitoring resumes after the complete catch-up is stored and acknowledged, including paginated, empty, and replayed batches.
- **System quota queries:** Send `/額度` or `/quota` in LINE to query Codex and Claude usage directly through the system, without MCP or an AI task. Claude's general quota controls availability; model-specific limits are shown separately.
- **Quota failure and switching:** Persist exhausted-quota flags and reset times. The system reports failures and asks to switch when another Agent is available. With consent, it changes the chat's Agent and retries the failed task. If neither Agent is available, it reports that state without switching back to a blocked Agent.
- **Repeated-failure notification fix:** Repeated quota failures for the same task still produce a switch prompt.

## 日本語

Windows x64 版です。インストール済みのアプリで「更新を確認」して更新できます。手動インストールは `LINE-Agent-Assistant-1.0.314-Setup-x64.exe`、ポータブル版は `LINE-Agent-Assistant-1.0.314.zip` です。SHA-256 は `SHA256SUMS.txt`、アプリ内更新には `latest.yml` と `.blockmap` を使用します。

前回の公開版 [v1.0.312](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.312) からの変更です。ローカル版 v1.0.313 の機能も含みます。

- **起動時の同期フラグ：** 起動・監視再開時の初期メッセージは保存だけ行い、Agent、自動返信、メッセージコマンドを起動しません。全ページの保存と同期確認が完了すると通常の監視に戻ります。空の応答と再送も同じフラグで処理します。
- **システムによる使用量確認：** LINE で `/額度` または `/quota` を送信すると、MCP や AI タスクを使わず Codex／Claude の使用量を確認できます。Claude 全体の上限で利用可否を判断し、モデル専用の上限は別に表示します。
- **上限到達時の通知と切替：** 制限フラグと回復時刻を保存し、利用可能な別の Agent がある場合は切替を確認します。同意するとチャットの Agent を変更し、失敗したタスクを再試行します。両方が利用不可の場合は状況を通知し、制限中の Agent に戻しません。
- **繰り返し失敗の通知修正：** 同じタスクで使用量制限が繰り返し発生しても切替の案内を作成します。

## 한국어

Windows x64 버전입니다. 설치된 앱에서 '업데이트 확인' 후 업데이트할 수 있습니다. 수동 설치 파일은 `LINE-Agent-Assistant-1.0.314-Setup-x64.exe`, 포터블 버전은 `LINE-Agent-Assistant-1.0.314.zip`입니다. SHA-256은 `SHA256SUMS.txt`에 있으며 앱 내 업데이트에는 `latest.yml`과 `.blockmap`을 사용합니다.

이전 공개 버전 [v1.0.312](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.312) 이후 변경 사항입니다. 로컬 v1.0.313 기능도 포함합니다.

- **시작 동기화 플래그:** 시작하거나 모니터링을 재개할 때 초기 메시지는 저장만 하며 Agent 작업, 자동 응답 또는 메시지 명령을 실행하지 않습니다. 모든 페이지의 저장과 동기화 확인이 끝나면 정상 모니터링을 재개합니다. 빈 응답과 재전송도 같은 플래그를 따릅니다.
- **시스템 사용량 조회:** LINE에서 `/額度` 또는 `/quota`를 보내면 MCP나 AI 작업 없이 Codex／Claude 사용량을 조회합니다. Claude 전체 한도로 사용 가능 여부를 판단하며 모델 전용 한도는 별도로 표시합니다.
- **한도 초과 안내와 전환:** 제한 플래그와 복구 시간을 저장하고 사용 가능한 다른 Agent가 있으면 전환 동의를 요청합니다. 동의하면 해당 채팅의 Agent를 변경하고 실패한 작업을 재시도합니다. 둘 다 사용할 수 없으면 현재 상태를 알리고 제한 중인 Agent로 되돌리지 않습니다.
- **반복 실패 알림 수정:** 같은 작업에서 사용량 제한이 반복되어도 전환 안내를 생성합니다.
