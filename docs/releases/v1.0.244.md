# v1.0.244 — changes since v1.0.207

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE.Agent.Assistant-1.0.244-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.244.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。

相較於上一個已發布版本 v1.0.207：

- 新增聊天室記事本與相簿保存、授權範圍內的 MCP 唯讀存取，以及 LINE 相簿通知自動保存；相簿工作會持久記錄，並可在應用程式重新啟動後繼續處理。
- 改善官方 LINE 監控、群組成員資訊、記事本與相簿通知、管理員好友關係處理及操作失敗診斷。
- 新增命令列結束與重啟入口，並改善聊天附件、對話資訊和設定頁紀錄的呈現。
- 改善相簿照片載入與分頁下載，並在 LINE 完成就緒後復原未完成的相簿工作；更清楚呈現相簿載入與下載失敗狀態，方便了解並重試。

相較於 v1.0.242：

- 改善相簿照片載入與分頁下載，並在 LINE 完成就緒後復原未完成的相簿工作。
- 提供更清楚的相簿載入與下載失敗狀態，方便使用者了解並重試。

先前從 v1.0.207 到 v1.0.242 的更新，請參閱 [v1.0.242 版本說明](v1.0.242.md)。

## English

Windows x64 release. Download `LINE.Agent.Assistant-1.0.244-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.244.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`.

Changes since the previous published release, v1.0.207:

- Added saved chat Notes and Albums, read-only MCP access within granted scopes, and automatic archiving of LINE Album notifications. Album tasks are stored durably and can resume after an application restart.
- Improved official LINE monitoring, group member details, Note and Album notifications, administrator friendship handling, and operational failure diagnostics.
- Added command-line quit and restart, and refined chat attachments, conversation details, and Settings records.
- Improved Album photo loading and paginated downloads, resumed unfinished Album tasks after LINE becomes ready, and clarified Album loading and download failures so users can retry.

Changes since v1.0.242:

- Improved Album photo loading and paginated downloads, and resumed unfinished Album tasks after LINE becomes ready.
- Added clearer Album loading and download failure status so users can understand and retry failed work.

For changes from v1.0.207 through v1.0.242, see the [v1.0.242 release notes](v1.0.242.md).

## 日本語

Windows x64 版です。**Assets** から `LINE.Agent.Assistant-1.0.244-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.244.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。

前回公開版 v1.0.207 からの変更点：

- トークのノートとアルバムの保存、許可された範囲での MCP 読み取り専用アクセス、LINE のアルバム通知の自動保存に対応しました。アルバム処理は永続化され、アプリの再起動後も続行できます。
- 公式 LINE 監視、グループメンバー情報、ノート／アルバム通知、管理者との友だち関係の処理、操作失敗の診断を改善しました。
- コマンドラインからの終了と再起動に対応し、トークの添付ファイル、会話情報、設定画面の記録表示を調整しました。
- アルバム写真の読み込みとページ送りによるダウンロードを改善し、LINE の準備完了後に未完了のアルバム処理を再開するようにしました。読み込みやダウンロードの失敗状態も分かりやすくしました。

v1.0.242 からの変更点：

- アルバム写真の読み込みとページ送りによるダウンロードを改善し、LINE の準備完了後に未完了のアルバム処理を再開するようにしました。
- アルバムの読み込みやダウンロードに失敗した状態を分かりやすくし、再試行できるようにしました。

v1.0.207 から v1.0.242 までの変更は、[v1.0.242 のリリースノート](v1.0.242.md)をご覧ください。
