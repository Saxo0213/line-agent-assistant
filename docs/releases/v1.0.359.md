# v1.0.359 — changes since v1.0.342

## 繁體中文

Windows x64 版本。可透過 App「檢查更新」安裝；手動安裝檔與免安裝版請見 GitHub v1.0.359 Release。

- **Claude 常駐執行：** Claude 的 LINE 與 Agent 室工作改在常駐程序上執行，不必每則訊息重新啟動。Agent 處理中同一人連續傳來的訊息，會合併成下一輪的一次回覆；Claude 在兩輪之間自行完成的回覆會轉送到原聊天室；新的工作階段會附上同一聊天室的近期對話紀錄。
- **多個 CLI 帳號來源與自動切換：** 「設定 → Agent」可為 Claude 與 Codex 各加入多個帳號來源，可排序、登入、登出、查看用量。額度用盡或被限速時自動改用下一個來源，被擋的來源恢復後再試；「自動切換來源」預設開啟。原本額度用盡時詢問是否改用其他 Agent 的流程已移除。`/quota` 會顯示目前使用的來源。
- **`/model` 指令：** 主要管理者可為每個聊天室指定 Claude 模型（haiku、sonnet、opus）或 Codex 模型。Codex 逾時會送出已產生的部分回覆；Codex 對話失效時會自動改開新對話再試一次。
- **Agent 讀取附件：** Agent 可直接讀取訊息的附件檔。已過期或下載失敗的附件，若「下載」資料夾有同名且大小相同的檔案，開啟附件時會從該檔復原。
- **下載登入：** 照片與檔案的下載間隔可自行設定（0–600 秒，預設 3–10 秒）；比對通過的新訊息照片與檔案立即下載。外部監控中斷後，7 天內仍未下載、且比對相同的照片與檔案會自動補下載。擴充功能尚未補上金鑰的訊息不再誤判為「不一致」，真正的不一致紀錄會一直保留。
- **連線保護：** LINE 伺服器連續拒絕時會逐步放慢並暫停輪詢，改顯示需要重新登入；左下角會列出連線異常的帳號。新增「LEGY 加密傳輸」設定，預設關閉。
- **外部監控：** 因暫時性錯誤停止時會自動重試（30 秒起，最長間隔 10 分鐘）；系統錯誤紀錄會保留實際錯誤代碼。
- **Agent 查詢群組事件：** Agent 讀取訊息時可看到「XXX加入聊天」「XXX已將YYY強制退出社群」等系統事件的文字，用成員名稱或成員編號也查得到相關事件。
- **其他修正：** Agent 工作失敗時顯示「Agent 工作失敗」與原因代碼；Agent 讀取大型檔案不再因輸出過長而失敗。

## English

Windows x64 release. Install through **Check for updates** in the app; the installer and portable build are available from the GitHub v1.0.359 release.

- **Resident Claude process:** Claude jobs for LINE chats and the Agent room run on a resident process instead of a new process for each message. Messages that one person sends while the Agent is busy are joined into one follow-up turn with one reply. Replies that Claude finishes on its own between turns are relayed to the chat. A new session starts with the recent transcript of the same chat.
- **Several CLI account sources with automatic failover:** **Settings → Agent** can hold several account sources for Claude and for Codex, with order, sign-in, sign-out and usage. When a source runs out of quota or is rate-limited, the next source is used, and a blocked source is tried again after it recovers. **Switch sources automatically** is on by default. The old prompt that asked whether to use another Agent after a quota failure is removed. `/quota` shows the source in use.
- **`/model` command:** The primary administrator can set the Claude model (haiku, sonnet, opus) or the Codex model of each chat. A Codex turn that times out sends its partial reply, and a lost Codex thread is retried once in a new thread.
- **Agent reads attachments:** The Agent can read the file of a message attachment. An expired or failed attachment is recovered when the user opens it and the **Downloads** folder has a file with the same name and size.
- **Download login:** The photo and file download intervals are adjustable (0–600 seconds, default 3–10). Verified photos and files of new messages download at once. After an external-monitor outage, photos and files of the last 7 days that are still queued and verify as a match download automatically. A message whose keys the extension has not filled in yet is no longer reported as a mismatch, and a real mismatch record is kept.
- **Connection protection:** When the LINE server rejects requests repeatedly, polling backs off and then stops, and the account asks for a new login. Accounts with a connection problem are listed at the bottom left. A new **LEGY encrypted transport** setting is off by default.
- **External monitor:** After a transient error it retries automatically (from 30 seconds up to 10 minutes between tries). System error records keep the real error code.
- **Group events for the Agent:** Agent message reads show the text of system events such as joins and removals from a community, and a member's name or id also finds those events.
- **Other fixes:** A failed Agent job shows **Agent 工作失敗** with its reason code; reading a large file no longer fails the Agent job because of long output.

## 日本語

Windows x64 版です。アプリの「更新を確認」から更新できます。インストーラーとポータブル版は GitHub v1.0.359 リリースから入手できます。

- **Claude の常駐実行：** LINE と Agent ルームの Claude ジョブは、メッセージごとに起動せず常駐プロセスで実行します。Agent の処理中に同じ人から届いたメッセージは次の 1 ターンにまとめて 1 回返信します。ターンの間に Claude が自分で完了した返信は元のチャットに送ります。新しいセッションでは同じチャットの最近のやり取りを添えます。
- **複数の CLI アカウントと自動切り替え：** 「設定 → Agent」で Claude と Codex にそれぞれ複数のアカウントを追加でき、順序、ログイン、ログアウト、使用量を管理できます。利用上限やレート制限に達すると次のアカウントに切り替え、制限されたアカウントは回復後に再試行します。「アカウントを自動で切り替える」は既定でオンです。上限到達時に別の Agent を使うか確認する流れは廃止しました。`/quota` に使用中のアカウントを表示します。
- **`/model` コマンド：** メイン管理者はチャットごとに Claude のモデル（haiku、sonnet、opus）または Codex のモデルを指定できます。Codex がタイムアウトした場合は生成済みの部分返信を送り、Codex のスレッドが失われた場合は新しいスレッドで 1 回再試行します。
- **Agent による添付ファイルの読み取り：** Agent はメッセージの添付ファイルを直接読めます。期限切れや失敗した添付ファイルは、「ダウンロード」フォルダーに同じ名前・同じサイズのファイルがあれば、開いたときにそこから復元します。
- **ダウンロード用ログイン：** 写真とファイルのダウンロード間隔を設定できます（0〜600 秒、既定 3〜10 秒）。照合済みの新しいメッセージの写真とファイルはすぐにダウンロードします。外部監視の停止後、7 日以内で未ダウンロードかつ照合が一致した写真とファイルは自動でダウンロードします。拡張機能が鍵をまだ持っていないメッセージは「不一致」と判定しなくなり、本当の不一致の記録は保持されます。
- **接続の保護：** LINE サーバーが続けて拒否した場合はポーリングを段階的に遅らせて停止し、再ログインが必要と表示します。接続に問題のあるアカウントを左下に表示します。「LEGY 暗号化通信」設定を追加しました（既定はオフ）。
- **外部監視：** 一時的なエラーで停止した場合は自動で再試行します（30 秒から、最長 10 分間隔）。システムエラーの記録に実際のエラーコードを残します。
- **Agent からグループイベントを参照：** Agent がメッセージを読むとき、参加やコミュニティからの強制退会などのシステムイベントの文面を取得でき、メンバー名やメンバー ID でも関連イベントを検索できます。
- **その他の修正：** Agent ジョブの失敗時に「Agent 工作失敗」と理由コードを表示します。大きなファイルを読んでも出力の長さが原因でジョブが失敗しなくなりました。

## 한국어

Windows x64 버전입니다. 앱의 '업데이트 확인'으로 설치할 수 있습니다. 설치 파일과 포터블 빌드는 GitHub v1.0.359 릴리스에서 받을 수 있습니다.

- **Claude 상주 실행:** LINE 대화와 Agent 방의 Claude 작업은 메시지마다 새로 시작하지 않고 상주 프로세스에서 실행합니다. Agent가 처리 중일 때 같은 사람이 보낸 메시지는 다음 한 번의 턴으로 합쳐 한 번 답장합니다. 턴 사이에 Claude가 스스로 완료한 답장은 원래 대화로 전달합니다. 새 세션은 같은 대화의 최근 기록을 함께 받습니다.
- **여러 CLI 계정과 자동 전환:** '설정 → Agent'에서 Claude와 Codex에 각각 여러 계정을 추가하고 순서, 로그인, 로그아웃, 사용량을 관리할 수 있습니다. 사용 한도에 도달하거나 속도 제한이 걸리면 다음 계정으로 전환하고, 막힌 계정은 회복된 뒤 다시 시도합니다. '자동으로 계정 전환'은 기본적으로 켜져 있습니다. 한도 초과 시 다른 Agent를 쓸지 묻던 흐름은 제거되었습니다. `/quota`에 현재 사용 중인 계정을 표시합니다.
- **`/model` 명령:** 주 관리자는 대화마다 Claude 모델(haiku, sonnet, opus) 또는 Codex 모델을 지정할 수 있습니다. Codex가 시간 초과되면 생성된 부분 답장을 보내고, Codex 스레드를 잃으면 새 스레드로 한 번 다시 시도합니다.
- **Agent의 첨부 파일 읽기:** Agent가 메시지 첨부 파일을 직접 읽을 수 있습니다. 만료되었거나 실패한 첨부 파일은 '다운로드' 폴더에 이름과 크기가 같은 파일이 있으면 열 때 그 파일로 복구합니다.
- **다운로드용 로그인:** 사진과 파일의 다운로드 간격을 설정할 수 있습니다(0~600초, 기본 3~10초). 대조를 통과한 새 메시지의 사진과 파일은 바로 다운로드합니다. 외부 모니터링이 중단된 뒤에는 7일 이내에 아직 대기 중이고 대조가 일치하는 사진과 파일을 자동으로 다운로드합니다. 확장 프로그램이 아직 키를 채우지 않은 메시지는 더 이상 '불일치'로 판정하지 않으며, 실제 불일치 기록은 유지됩니다.
- **연결 보호:** LINE 서버가 연속으로 거부하면 폴링을 점점 늦추다가 멈추고 다시 로그인이 필요하다고 표시합니다. 연결에 문제가 있는 계정은 왼쪽 아래에 표시합니다. 'LEGY 암호화 전송' 설정을 추가했습니다(기본값 꺼짐).
- **외부 모니터링:** 일시적인 오류로 멈추면 자동으로 다시 시도합니다(30초부터 최대 10분 간격). 시스템 오류 기록에 실제 오류 코드를 남깁니다.
- **Agent의 그룹 이벤트 조회:** Agent가 메시지를 읽을 때 참여, 커뮤니티 강제 퇴장 같은 시스템 이벤트의 문구를 볼 수 있고, 멤버 이름이나 멤버 ID로도 관련 이벤트를 찾을 수 있습니다.
- **기타 수정:** Agent 작업이 실패하면 'Agent 工作失敗'와 원인 코드를 표시합니다. 큰 파일을 읽어도 출력 길이 때문에 Agent 작업이 실패하지 않습니다.
