## 繁體中文

- **環境檢查與登入說明：** 設定頁標題右側新增「環境檢查」與「登入說明」兩個按鈕，點擊才開啟視窗；有缺少的工具或未完成的登入步驟時，按鈕上會顯示小圓點。環境檢查涵蓋 Chrome、LINE Chrome 擴充功能 3.7.2、電腦版 LINE、Node.js、Claude CLI、Codex CLI。缺少的項目可按「安裝」：Chrome、擴充功能與電腦版 LINE 開啟官方下載頁；Node.js 用 winget 安裝；Claude 執行官方安裝程式；Codex 執行 `npm.cmd install -g @openai/codex`。安裝在看得到的 PowerShell 視窗進行，不更改 PowerShell 執行原則，視窗關閉後自動重新檢查。
- **CLI 偵測：** 接受 Node.js 24 以上（含 26）。App 啟動後才安裝的 Node.js、Claude、Codex，不必重開 App 也能找到。也會找 `%USERPROFILE%\.local\bin\claude.exe`。
- **外部監控：** 啟動失敗時顯示實際原因代碼與說明，不再只有 `external_monitor_reader_startup_failed`；讀取元件在每次啟動外部監控時重試。找不到 LINE Chrome 擴充功能時提供「前往安裝」按鈕。
- **接收社群：** 登入時讀取一次帳號是否綁定電話號碼。未綁定電話的帳號無法加入社群，「接收社群訊息」會停用並說明原因。
- **登入畫面：** 登入方式改為有標籤的分段選擇，和登入按鈕分開。
- **移除：** 「LINE 連結查詢（測試）」已移除。

## English

- **Environment check and login guide:** Two new buttons at the right of the Settings title, **Environment check** and **Login guide**, open each one in a dialog. A dot on the button shows a missing tool or an unfinished login step. The environment check covers Chrome, the LINE Chrome extension 3.7.2, desktop LINE, Node.js, Claude CLI and Codex CLI. A missing item has an **Install** button: Chrome, the extension and desktop LINE open the official download page; Node.js installs with winget; Claude runs the official installer; Codex runs `npm.cmd install -g @openai/codex`. Installs run in a visible PowerShell window, do not change the PowerShell execution policy, and the check runs again when the window closes.
- **CLI detection:** Node.js 24 or higher (including 26) is accepted. Node.js, Claude and Codex installed after the app started are found without a restart. `%USERPROFILE%\.local\bin\claude.exe` is also found.
- **External monitor:** A start failure shows the real reason code and text, not only `external_monitor_reader_startup_failed`. The reader component retries on each external monitor start. When the LINE Chrome extension is not found, a **Go to install** button is shown.
- **Community receive:** At login the app reads once whether the account has a phone number. An account without a phone cannot join communities, so **Receive community messages** is disabled with the reason.
- **Login screen:** The login method is a labeled segmented control, separate from the login button.
- **Removed:** **LINE link lookup (test)** is removed.

## 日本語

- **環境チェックとログインの説明：** 設定のタイトル右側に「環境チェック」と「ログインの説明」の 2 つのボタンを追加し、押すとそれぞれのウィンドウを開きます。不足しているツールや未完了のログイン手順があると、ボタンに小さな点を表示します。環境チェックでは Chrome、LINE Chrome 拡張機能 3.7.2、LINE（PC 版）、Node.js、Claude CLI、Codex CLI を確認します。不足している項目は「インストール」を押せます。Chrome、拡張機能、LINE（PC 版）は公式ダウンロードページを開き、Node.js は winget で、Claude は公式インストーラーで、Codex は `npm.cmd install -g @openai/codex` でインストールします。インストールは表示される PowerShell ウィンドウで行い、PowerShell の実行ポリシーは変更しません。ウィンドウを閉じると自動で再チェックします。
- **CLI の検出：** Node.js 24 以上（26 を含む）に対応しました。アプリ起動後にインストールした Node.js、Claude、Codex も再起動なしで検出します。`%USERPROFILE%\.local\bin\claude.exe` も検出します。
- **外部監視：** 起動に失敗したとき、`external_monitor_reader_startup_failed` だけでなく実際の理由コードと説明を表示します。読み取りコンポーネントは外部監視の開始ごとに再試行します。LINE Chrome 拡張機能が見つからない場合は「インストールへ」ボタンを表示します。
- **オープンチャットの受信：** ログイン時にアカウントの電話番号登録を 1 回確認します。電話番号のないアカウントはオープンチャットに参加できないため、「オープンチャットのメッセージを受信」を理由付きで無効にします。
- **ログイン画面：** ログイン方法をラベル付きのセグメント選択にし、ログインボタンと分けました。
- **削除：** 「LINE リンク検索（テスト）」を削除しました。

## 한국어

- **환경 점검과 로그인 안내:** 설정 제목 오른쪽에 '환경 점검'과 '로그인 안내' 버튼을 추가했고, 누르면 각각 창이 열립니다. 빠진 도구나 끝나지 않은 로그인 단계가 있으면 버튼에 작은 점이 표시됩니다. 환경 점검은 Chrome, LINE Chrome 확장 프로그램 3.7.2, PC 버전 LINE, Node.js, Claude CLI, Codex CLI를 확인합니다. 빠진 항목은 '설치'를 누를 수 있습니다. Chrome, 확장 프로그램, PC 버전 LINE은 공식 다운로드 페이지를 열고, Node.js는 winget으로, Claude는 공식 설치 프로그램으로, Codex는 `npm.cmd install -g @openai/codex`로 설치합니다. 설치는 보이는 PowerShell 창에서 진행하며 PowerShell 실행 정책은 바꾸지 않습니다. 창을 닫으면 자동으로 다시 점검합니다.
- **CLI 감지:** Node.js 24 이상(26 포함)을 지원합니다. 앱 실행 후 설치한 Node.js, Claude, Codex도 앱을 다시 시작하지 않고 찾습니다. `%USERPROFILE%\.local\bin\claude.exe`도 찾습니다.
- **외부 모니터링:** 시작에 실패하면 `external_monitor_reader_startup_failed`만이 아니라 실제 원인 코드와 설명을 표시합니다. 읽기 구성 요소는 외부 모니터링을 시작할 때마다 다시 시도합니다. LINE Chrome 확장 프로그램을 찾지 못하면 '설치하러 가기' 버튼을 표시합니다.
- **오픈채팅 수신:** 로그인할 때 계정의 전화번호 등록 여부를 한 번 확인합니다. 전화번호가 없는 계정은 오픈채팅에 참여할 수 없으므로 '오픈채팅 메시지 수신'을 이유와 함께 비활성화합니다.
- **로그인 화면:** 로그인 방법을 라벨이 있는 분할 선택으로 바꾸고 로그인 버튼과 분리했습니다.
- **제거:** 'LINE 링크 조회(테스트)'를 제거했습니다.
