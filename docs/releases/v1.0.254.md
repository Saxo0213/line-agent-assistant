# v1.0.254 — changes since v1.0.244

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE.Agent.Assistant-1.0.254-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.254.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。

相較於上一個公開版本 v1.0.244：

- 相簿清單會顯示封面；相簿照片可顯示預覽與本機儲存狀態，已儲存的照片使用易辨識的資料夾與檔名。
- 相簿與照片的掃描結果會保留，後續瀏覽可以重用，重複照片的處理也減少了。
- 記事本或相簿讀取失敗時，帳號會維持連線，下一次讀取會重新取得存取憑證。
- 暫停從通知自動抓取記事本。
- 修正部分系統紀錄無法儲存的問題。
- 社群成員加入會以系統通知顯示；社群與群組的記事本通知（包含已刪除的通知）會顯示為發送者的訊息。
- 無法開啟的連結會顯示「無法開啟連結」；操作失敗資訊會更清楚指出發生問題的操作。
- 記錄主要管理員已確認為 LINE 好友的狀態，管理員變更後會重新確認。

## English

Windows x64 release. Download `LINE.Agent.Assistant-1.0.254-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.254.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`.

Changes since the previous public release, v1.0.244:

- The Album list shows covers. Album photos show previews and whether they are saved locally, and saved photos use readable folder and file names.
- Album and photo scans keep their progress for later browsing, with less repeated work on duplicate photos.
- When a Note or Album read fails, the account stays connected and the next read gets fresh access credentials.
- Automatic Note fetching from notifications is paused.
- Fixed some system records that could not be saved.
- Community member joins are shown as system notices. Note notifications in communities and groups, including deleted ones, are shown as the sender's message.
- Links that cannot be opened now say so. Operation failures give clearer information about which action failed.
- The app remembers when the primary administrator has been confirmed as a LINE friend and checks again if the administrator changes.

## 日本語

Windows x64 版です。**Assets** から `LINE.Agent.Assistant-1.0.254-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.254.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。

前回の公開版 v1.0.244 からの変更点：

- アルバム一覧にカバーを表示します。アルバム写真のプレビューとローカル保存状態を表示し、保存した写真は分かりやすいフォルダー名とファイル名を使います。
- アルバムと写真のスキャン結果を保存し、次回の閲覧で再利用できるようにしました。重複写真の処理も減らしました。
- ノートやアルバムの読み込みに失敗しても、アカウントは接続されたままになり、次回の読み込みで新しいアクセス資格情報を取得します。
- 通知からのノート自動取得を一時停止しました。
- 一部のシステム記録が保存できない問題を修正しました。
- コミュニティのメンバー参加はシステム通知として表示します。コミュニティとグループのノート通知（削除済みを含む）は送信者のメッセージとして表示します。
- 開けないリンクはその旨を表示します。どの操作で失敗したかが分かりやすくなりました。
- 主要管理者が LINE の友だちであることを確認した状態を記録し、管理者が変更された場合は再確認します。

## 한국어

Windows x64 버전입니다. **Assets**에서 `LINE.Agent.Assistant-1.0.254-Setup-x64.exe`를 다운로드하세요. `LINE-Agent-Assistant-1.0.254.zip`은 포터블 버전입니다. SHA-256 값은 `SHA256SUMS.txt`에 있습니다.

이전 공개 버전 v1.0.244 이후 변경 사항:

- 앨범 목록에 커버를 표시합니다. 앨범 사진 미리보기와 로컬 저장 여부를 표시하며, 저장한 사진은 알아보기 쉬운 폴더명과 파일명을 사용합니다.
- 앨범과 사진 스캔 결과를 저장해 다음에 탐색할 때 재사용하고, 중복 사진 처리도 줄였습니다.
- 노트나 앨범 읽기에 실패해도 계정 연결이 유지되며, 다음 읽기에서 새 액세스 자격 증명을 받습니다.
- 알림에서 노트를 자동으로 가져오는 기능을 일시 중지했습니다.
- 일부 시스템 기록이 저장되지 않던 문제를 수정했습니다.
- 커뮤니티 멤버 참여는 시스템 알림으로 표시합니다. 커뮤니티와 그룹의 노트 알림(삭제된 알림 포함)은 보낸 사람의 메시지로 표시합니다.
- 열 수 없는 링크는 그렇다고 표시합니다. 어떤 작업에서 실패했는지 더 명확하게 확인할 수 있습니다.
- 기본 관리자가 LINE 친구로 확인된 상태를 기억하고, 관리자 정보가 바뀌면 다시 확인합니다.
