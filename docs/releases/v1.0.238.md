# v1.0.238 — changes since v1.0.207

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE.Agent.Assistant-1.0.238-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.238.zip` 是免安裝版。檔案的 SHA-256 值列於 `SHA256SUMS.txt`。

相較於上一個開源版本 v1.0.207：

- 新增聊天室記事本、相簿的保存與授權範圍內的 MCP 唯讀存取；開啟相簿時會把照片存入對應的相簿資料夾。
- 改善官方 LINE 外部監控的啟動、錯誤分類，以及群組成員與記事本／相簿通知的呈現。
- 新增命令列結束與重啟入口；自動登入只在程式啟動時嘗試一次，失敗或使用中登出後不會反覆登入。
- 調整聊天附件與開啟、回覆、已讀、時間的排列，並統一設定頁紀錄卡片寬度。
- 擴充系統操作與失敗診斷紀錄，方便辨認失敗步驟。

## English

Windows x64 release. Download `LINE.Agent.Assistant-1.0.238-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.238.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`.

Changes since the previous public release, v1.0.207:

- Added saved chat Notes and Albums with read-only MCP access within granted scopes. Opening an Album saves its photos in a folder for that Album.
- Improved startup and error reporting for official LINE monitoring, and presentation of group membership and Note/Album notifications.
- Added command-line quit and restart. Automatic sign-in is attempted once at startup; a failure or later sign-out does not cause repeated automatic sign-in.
- Refined chat attachments and the alignment of Open, Reply, Read, and time labels; matched the Records card width to other Settings cards.
- Expanded operational and failure diagnostics to identify the failing stage.

## 日本語

Windows x64 版です。**Assets** から `LINE.Agent.Assistant-1.0.238-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.238.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。

前回の公開版 v1.0.207 からの変更点：

- トークのノートとアルバムの保存、および許可された範囲での MCP 読み取りに対応。アルバムを開くと写真を対応するフォルダーに保存します。
- 公式 LINE の外部監視の起動とエラー表示、グループメンバーおよびノート／アルバム通知の表示を改善しました。
- コマンドラインからの終了と再起動に対応。自動ログインは起動時に一度だけ試行します。
- トークの添付ファイルと「開く・返信・既読・時刻」の配置、設定画面の記録カード幅を調整しました。
- 操作と失敗の診断記録を拡充しました。
