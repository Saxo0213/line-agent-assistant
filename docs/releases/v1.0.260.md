# v1.0.260 — changes since v1.0.258

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE.Agent.Assistant-1.0.260-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.260.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。

相較於上一個公開版本 v1.0.258：

- 可明確更換 Agent LINE 帳號。舊帳號的聊天與附件會留在舊帳號；新帳號會有自己的獨立資料。
- 新發生的系統錯誤會記錄經驗證的 IPC 動作名稱，方便判斷是哪項操作失敗。歷史錯誤會標示動作名稱未記錄。
- 本程式仍為非官方專案，與 LINE 無隸屬、背書或贊助關係。

## English

Windows x64 release. Download `LINE.Agent.Assistant-1.0.260-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.260.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`.

Changes since the previous public release, v1.0.258:

- You can explicitly replace the Agent LINE account. Chats and attachments remain with the old account, and the replacement account has separate data.
- New System Errors record the validated IPC action name to identify which action failed. Historical errors clearly state that the action was not recorded.
- This remains an unofficial project and is not affiliated with, endorsed by, or sponsored by LINE or its affiliates.

## 日本語

Windows x64 版です。**Assets** から `LINE.Agent.Assistant-1.0.260-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.260.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。

前回の公開版 v1.0.258 からの変更点：

- Agent の LINE アカウントを明示的に置き換えられるようになりました。以前のアカウントのトークと添付ファイルは旧アカウントに残り、新しいアカウントには別のデータが作成されます。
- 新しいシステムエラーには検証済みの IPC 操作名が記録され、どの操作が失敗したかを確認できます。過去のエラーでは操作名が記録されていないことが明示されます。
- 本アプリは引き続き非公式プロジェクトであり、LINE およびその関連会社とは提携・承認・支援関係にありません。
