# v1.0.305 — changes since v1.0.303

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE-Agent-Assistant-1.0.305-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.305.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。`latest.yml` 與 `.blockmap` 供 App 內自動更新使用；已安裝 v1.0.303 的使用者可直接在右下角提示選擇「更新」。

相較於上一個公開版本 [v1.0.303](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.303)：

- **MCP 不再需要 Token**：Claude Desktop 與 Codex 連線到本機 MCP 時不需要 Token，也不會再因為 Token 被撤銷而連線失敗。設定頁的 Token 核發、清單、撤銷與帳號範圍選項已移除。
- **安全性變更，請注意**：這台電腦上的任何程式都能不用密碼，透過 `127.0.0.1` 讀取已儲存的 LINE 訊息紀錄，範圍是 Agent 與主要管理者帳號。瀏覽器網頁會被 `Origin` 與 `Host` 檢查擋下。外部連線仍然只能讀取，不能傳送 LINE。如果這台電腦有你不信任的使用者或程式，請不要連接外部 MCP，也不要使用這個版本。
- 既有的 Claude Desktop／Codex 設定可繼續使用，不需要重新連接；設定檔內的舊 Token 會被忽略，下次按「連接」時會移除。
- 內建 Agent 工作的聊天室範圍與權限維持不變。
- 外部監控卡片：開始監控後不再顯示固定不變的「已提交」數字（只在第一次匯入時顯示），「監控中」與「關閉外部監控」移到「LINE 版本」同一行。
- 本程式仍為非官方專案，與 LINE 無隸屬、背書或贊助關係。

## English

Windows x64 release. Download `LINE-Agent-Assistant-1.0.305-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.305.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`. `latest.yml` and the `.blockmap` are used by the in-app updater; if v1.0.303 is installed, choose Update in the bottom-right prompt.

Changes since the previous public release, [v1.0.303](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.303):

- **MCP no longer uses tokens:** Claude Desktop and Codex connect to the local MCP endpoint with no token, so a revoked token can no longer break the connection. Token issue, list, revoke, and the account scope options are removed from Settings.
- **Security change, please read:** any program on this computer can read stored LINE messages through `127.0.0.1` with no password, for the Agent and Primary Admin accounts. Browser pages are rejected by `Origin` and `Host` checks. External connections stay read-only and cannot send LINE messages. If this computer has users or programs that you do not trust, do not connect external MCP clients and do not use this version.
- Existing Claude Desktop and Codex configurations keep working with no reconnect. An old token in the configuration is ignored, and the next Connect removes it.
- The chat scope and permissions of built-in Agent jobs do not change.
- External Monitor card: after monitoring starts, the fixed "Committed" count no longer shows (it shows only during the first import). "Monitoring" and "Stop external monitoring" move to the LINE version row.
- This remains an unofficial project and is not affiliated with, endorsed by, or sponsored by LINE or its affiliates.

## 日本語

Windows x64 版です。**Assets** から `LINE-Agent-Assistant-1.0.305-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.305.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。`latest.yml` と `.blockmap` はアプリ内の自動更新で使用します。v1.0.303 をお使いの場合は、右下の通知で「更新」を選べます。

前回の公開版 [v1.0.303](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.303) からの変更点：

- **MCP でトークンが不要になりました**：Claude Desktop と Codex はトークンなしでローカル MCP に接続します。トークンの失効で接続できなくなることはありません。設定画面のトークン発行、一覧、失効、アカウント範囲の項目を削除しました。
- **セキュリティの変更点（ご確認ください）**：このコンピューター上のどのプログラムも、パスワードなしで `127.0.0.1` 経由で保存済みの LINE メッセージを読み取れます。対象は Agent とプライマリ管理者のアカウントです。ブラウザーのページは `Origin` と `Host` の確認で拒否します。外部接続は引き続き読み取り専用で、LINE を送信できません。信頼できないユーザーやプログラムがあるコンピューターでは、外部 MCP を接続せず、このバージョンを使用しないでください。
- 既存の Claude Desktop／Codex の設定は再接続なしで使えます。設定内の古いトークンは無視され、次に「接続」を押したときに削除されます。
- 内蔵 Agent ジョブのトーク範囲と権限は変わりません。
- 外部モニターカード：監視の開始後は固定の「コミット済み」件数を表示しません（初回インポート中のみ表示）。「監視中」と「外部モニターを停止」を LINE バージョンの行に移しました。
- 本アプリは引き続き非公式プロジェクトであり、LINE およびその関連会社とは提携・承認・支援関係にありません。

## 한국어

Windows x64 버전입니다. **Assets**에서 `LINE-Agent-Assistant-1.0.305-Setup-x64.exe`를 다운로드하세요. `LINE-Agent-Assistant-1.0.305.zip`은 포터블 버전입니다. SHA-256 값은 `SHA256SUMS.txt`에 있습니다. `latest.yml`과 `.blockmap`은 앱 내 자동 업데이트에 사용됩니다. v1.0.303을 사용 중이면 오른쪽 아래 알림에서 '업데이트'를 선택하면 됩니다.

이전 공개 버전 [v1.0.303](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.303) 이후 변경 사항:

- **MCP에 토큰이 필요 없습니다**: Claude Desktop과 Codex는 토큰 없이 로컬 MCP에 연결합니다. 토큰이 폐기되어 연결이 끊기는 일이 없습니다. 설정의 토큰 발급, 목록, 폐기, 계정 범위 항목을 제거했습니다.
- **보안 변경 사항(꼭 확인하세요)**: 이 컴퓨터의 모든 프로그램이 비밀번호 없이 `127.0.0.1`을 통해 저장된 LINE 메시지를 읽을 수 있습니다. 대상은 Agent와 기본 관리자 계정입니다. 브라우저 페이지는 `Origin`과 `Host` 검사로 거부됩니다. 외부 연결은 계속 읽기 전용이며 LINE을 보낼 수 없습니다. 신뢰할 수 없는 사용자나 프로그램이 있는 컴퓨터에서는 외부 MCP를 연결하지 말고 이 버전을 사용하지 마세요.
- 기존 Claude Desktop／Codex 설정은 다시 연결하지 않아도 계속 작동합니다. 설정의 이전 토큰은 무시되며, 다음에 '연결'을 누르면 제거됩니다.
- 내장 Agent 작업의 채팅 범위와 권한은 바뀌지 않습니다.
- 외부 모니터 카드: 모니터링을 시작한 뒤에는 고정된 '커밋됨' 숫자를 표시하지 않습니다(첫 가져오기 중에만 표시). '모니터링 중'과 '외부 모니터 중지'를 LINE 버전 줄로 옮겼습니다.
- 이 앱은 계속 비공식 프로젝트이며 LINE 또는 그 계열사와 제휴 관계가 없고, 이들의 승인이나 후원을 받지 않습니다.
