## 繁體中文

- **下載用登入：** 修正下載用 Chrome 啟動後立即結束（結束代碼 0）、狀態停在「啟動中」的問題。原因是另一個 Chrome（例如「從商店安裝擴充功能」開啟的視窗留在背景）仍在使用下載用設定檔。現在啟動前會關閉所有使用 App 專用下載設定檔的 Chrome，商店安裝結束後也會關閉；其他設定檔的 Chrome 不受影響。

## English

- **Download login:** Fixed a problem where the download Chrome ended right after the start (exit code 0) and the status stayed at "Starting". Another Chrome still used the download profile, for example the window of **Install extension from store** that stayed in the background. Before a start, and after a store install, the app now closes every Chrome that uses its own download profile. Chrome with any other profile is not affected.

## 日本語

- **ダウンロード用ログイン：** ダウンロード用 Chrome が起動直後に終了し（終了コード 0）、状態が「起動中」のまま止まる問題を修正しました。別の Chrome（例：「ストアから拡張機能をインストール」で開いたウィンドウがバックグラウンドに残ったもの）がダウンロード用プロファイルを使い続けていたことが原因です。起動前とストアからのインストール後に、アプリ専用のダウンロード用プロファイルを使う Chrome をすべて閉じるようにしました。ほかのプロファイルの Chrome には影響しません。

## 한국어

- **다운로드용 로그인:** 다운로드용 Chrome이 시작 직후 종료되고(종료 코드 0) 상태가 '시작 중'에 멈추던 문제를 수정했습니다. 다른 Chrome(예: '스토어에서 확장 프로그램 설치'로 연 창이 백그라운드에 남은 것)이 다운로드용 프로필을 계속 사용하고 있던 것이 원인입니다. 이제 시작 전과 스토어 설치가 끝난 뒤, 앱 전용 다운로드 프로필을 쓰는 Chrome을 모두 닫습니다. 다른 프로필의 Chrome에는 영향이 없습니다.
