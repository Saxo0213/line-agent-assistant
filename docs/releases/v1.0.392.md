## 繁體中文

- **群組不必再啟用 Agent：** 移除「@Agent 監控」群組啟用。群組只檢查白名單：帳號範圍的成員可在 Agent 帳號所在的所有群組使用 Agent，只加在某個群組的成員只能在那個群組使用；自由模式只檢查自己的開啟期限。在群組輸入 `/權限` 會回覆提示：請改在與 Agent 的一對一聊天使用，加入白名單請用 `/新增使用者`。
- **Codex 基本對話：** 沒有「本機工作區」權限的成員也能用 Codex 對話、查詢 LINE 紀錄。這時 Codex 以唯讀方式執行，關閉執行指令、讀取檔案與瀏覽器功能，不再整個失敗（`PROVIDER_TOOLS_UNSUPPORTED`）。
- **下載用登入：** 優先使用從 Chrome 線上應用程式商店安裝到下載用 Chrome 的 LINE 擴充功能；開發者載入只作為備援。載入失敗時會出現「從商店安裝擴充功能」按鈕：在開啟的 Chrome 視窗按「加到 Chrome」，關閉視窗後自動繼續登入。改以程式碼特徵檢查擴充功能，不再比對版本號；登入或下載方式有變動時會明確提示。「清除下載登入」不會移除從商店安裝的擴充功能。
- **錯誤原因：** 下載用 Chrome 啟動或載入失敗時，系統錯誤會記錄 Chrome 回報的原因（已移除路徑等內容）。
- **外部監控：** 修正以系統管理員帳號、在 UAC 限制下啟動外部監控時，因私人資料夾權限設定失敗（`private_directory_acl_command_failed`）而無法啟動的問題。
- **已儲存檔案：** 視窗標題列新增「開啟資料夾」按鈕，直接開啟該聊天室存放檔案的資料夾。

## English

- **No group activation:** The **@Agent monitor** group activation is removed. A group now checks only the whitelist: a member whitelisted for the account can use the Agent in every group of the Agent account, and a member whitelisted for one group can use it only in that group. Free mode checks only its own time window. `/permissions` in a group replies with a hint: use it in the one-to-one chat with the Agent, and use `/adduser` to add a member to the whitelist.
- **Codex basic chat:** A member without the **local workspace** permission can now chat with Codex and query LINE records. Codex then runs read-only, with command execution, file reading and browser features turned off, instead of failing with `PROVIDER_TOOLS_UNSUPPORTED`.
- **Download login:** The LINE extension installed from the Chrome Web Store into the download Chrome comes first. The developer load is only a fallback. When loading fails, an **Install extension from store** button appears: click **Add to Chrome** in the window that opens, close the window, and the login continues. The extension is checked by code features instead of the version number, with a clear message when the login or download method has changed. **Clear download login** keeps the store-installed extension.
- **Error reasons:** When the download Chrome fails to start or to load the extension, the system error records the reason that Chrome reports, with paths removed.
- **External monitor:** Fixed a start failure (`private_directory_acl_command_failed`) for an administrator account under UAC, caused by the private folder permission step.
- **Saved files:** The dialog header has a new **Open folder** button that opens the folder of the chat's saved files.

## 日本語

- **グループの有効化が不要に：** 「@Agent 監視」によるグループの有効化を削除しました。グループではホワイトリストだけを確認します。アカウント単位で登録したメンバーは Agent アカウントが参加しているすべてのグループで、特定のグループだけに登録したメンバーはそのグループでのみ Agent を使えます。フリーモードは自分の期限だけを確認します。グループで `/權限` を送ると、Agent との 1 対 1 チャットで使うこと、ホワイトリストへの追加は `/新增使用者` を使うことを案内します。
- **Codex の基本的な会話：** 「ローカルワークスペース」権限のないメンバーも Codex と会話し、LINE の記録を検索できます。この場合 Codex は読み取り専用で動き、コマンド実行、ファイル読み取り、ブラウザー機能をオフにします。`PROVIDER_TOOLS_UNSUPPORTED` で失敗しなくなりました。
- **ダウンロード用ログイン：** ダウンロード用 Chrome に Chrome ウェブストアからインストールした LINE 拡張機能を優先して使い、デベロッパー読み込みは予備の手段にしました。読み込みに失敗すると「ストアから拡張機能をインストール」ボタンが表示されます。開いた Chrome ウィンドウで「Chrome に追加」を押してウィンドウを閉じると、ログインが続行されます。拡張機能はバージョン番号ではなくコードの特徴で確認し、ログインやダウンロードの方法が変わった場合ははっきり表示します。「ダウンロード用ログインを消去」はストアからインストールした拡張機能を削除しません。
- **エラーの理由：** ダウンロード用 Chrome の起動や拡張機能の読み込みに失敗したとき、Chrome が報告した理由（パスなどは除去）をシステムエラーに記録します。
- **外部監視：** UAC の制限下の管理者アカウントで、プライベートフォルダーの権限設定に失敗して（`private_directory_acl_command_failed`）外部監視を開始できない問題を修正しました。
- **保存済みファイル：** ダイアログのタイトル部分に「フォルダーを開く」ボタンを追加し、そのチャットのファイルを保存したフォルダーを直接開けるようにしました。

## 한국어

- **그룹 활성화 불필요:** '@Agent 모니터' 그룹 활성화를 제거했습니다. 그룹에서는 화이트리스트만 확인합니다. 계정 단위로 등록한 멤버는 Agent 계정이 있는 모든 그룹에서, 특정 그룹에만 등록한 멤버는 그 그룹에서만 Agent를 사용할 수 있습니다. 자유 모드는 자신의 사용 기간만 확인합니다. 그룹에서 `/權限`을 보내면 Agent와의 1:1 채팅에서 사용하고, 화이트리스트 추가는 `/新增使用者`를 사용하라는 안내를 답합니다.
- **Codex 기본 대화:** '로컬 작업 공간' 권한이 없는 멤버도 Codex와 대화하고 LINE 기록을 조회할 수 있습니다. 이때 Codex는 읽기 전용으로 실행되며 명령 실행, 파일 읽기, 브라우저 기능이 꺼집니다. 더 이상 `PROVIDER_TOOLS_UNSUPPORTED`로 실패하지 않습니다.
- **다운로드용 로그인:** 다운로드용 Chrome에 Chrome 웹 스토어에서 설치한 LINE 확장 프로그램을 우선 사용하고, 개발자 로드는 예비 수단으로만 사용합니다. 로드에 실패하면 '스토어에서 확장 프로그램 설치' 버튼이 나타납니다. 열린 Chrome 창에서 'Chrome에 추가'를 누르고 창을 닫으면 로그인이 이어집니다. 확장 프로그램은 버전 번호 대신 코드 특징으로 확인하며, 로그인이나 다운로드 방식이 바뀌면 분명하게 알려 줍니다. '다운로드 로그인 지우기'는 스토어에서 설치한 확장 프로그램을 지우지 않습니다.
- **오류 원인:** 다운로드용 Chrome의 시작이나 확장 프로그램 로드에 실패하면 Chrome이 보고한 원인(경로 등은 제거)을 시스템 오류에 기록합니다.
- **외부 모니터링:** UAC 제한을 받는 관리자 계정에서 개인 폴더 권한 설정 실패(`private_directory_acl_command_failed`)로 외부 모니터링을 시작하지 못하던 문제를 수정했습니다.
- **저장된 파일:** 창 제목 줄에 '폴더 열기' 버튼을 추가해, 그 채팅의 파일이 저장된 폴더를 바로 열 수 있습니다.
