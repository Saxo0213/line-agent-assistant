# v1.0.242 — changes since v1.0.207

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE.Agent.Assistant-1.0.242-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.242.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。

相較於上一個公開版本 v1.0.207：

- 新增聊天室記事本、相簿保存、授權範圍內的 MCP 唯讀存取，以及 LINE 相簿通知的自動保存；相簿工作會持久記錄，可在應用程式重新啟動後繼續處理。
- 改善官方 LINE 監控、群組成員資訊、記事本與相簿通知、管理員好友關係處理及操作失敗診斷。
- 新增命令列結束與重啟入口；改善聊天附件、對話資訊與設定頁紀錄的呈現。

相較於 v1.0.241：

- 將自動相簿通知工作持久化，並在完成或重試時確認帳號控制權仍有效；來源訊息已刪除或無效時會略過工作。

## English

Windows x64 release. Download `LINE.Agent.Assistant-1.0.242-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.242.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`.

Changes since the previous public release, v1.0.207:

- Added saved chat Notes and Albums, read-only MCP access within granted scopes, and automatic archiving of LINE Album notifications. Album tasks are stored durably and can resume after an application restart.
- Improved official LINE monitoring, group member details, Note and Album notifications, administrator friendship handling, and operational failure diagnostics.
- Added command-line quit and restart, and refined chat attachments, conversation details, and Settings records.

Changes since v1.0.241:

- Persisted automatic Album notification tasks and fenced completion and retry against current account control. Tasks with deleted or invalid source messages are skipped.

## 日本語

Windows x64 版です。**Assets** から `LINE.Agent.Assistant-1.0.242-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.242.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。

前回の公開版 v1.0.207 からの変更点：

- トークのノートとアルバムの保存、許可された範囲での MCP 読み取り専用アクセス、LINE のアルバム通知の自動保存に対応しました。アルバム処理は永続化され、アプリの再起動後も続行できます。
- 公式 LINE 監視、グループメンバー情報、ノート／アルバム通知、管理者との友だち関係の処理、操作失敗の診断を改善しました。
- コマンドラインからの終了と再起動に対応し、トークの添付ファイル、会話情報、設定画面の記録表示を調整しました。

v1.0.241 からの変更点：

- アルバム通知の自動処理を永続化し、現在のアカウント制御権限を確認してから完了または再試行するようにしました。削除済みまたは無効な元メッセージの処理はスキップします。

## 한국어

Windows x64 버전입니다. **Assets**에서 `LINE.Agent.Assistant-1.0.242-Setup-x64.exe`를 다운로드하세요. `LINE-Agent-Assistant-1.0.242.zip`은 포터블 버전입니다. SHA-256 값은 `SHA256SUMS.txt`에 있습니다.

이전 공개 버전 v1.0.207 이후 변경 사항:

- 채팅 노트와 앨범 저장, 허용된 범위의 MCP 읽기 전용 접근, LINE 앨범 알림 자동 저장을 추가했습니다. 앨범 작업은 영구 저장되어 앱을 다시 시작한 뒤에도 이어서 처리할 수 있습니다.
- 공식 LINE 모니터링, 그룹 구성원 정보, 노트 및 앨범 알림, 관리자 친구 관계 처리, 작업 실패 진단을 개선했습니다.
- 명령줄 종료와 다시 시작을 추가하고 채팅 첨부 파일, 대화 정보, 설정 화면 기록 표시를 다듬었습니다.

v1.0.241 이후 변경 사항:

- 앨범 알림 자동 작업을 저장하고, 완료 또는 재시도 전에 현재 계정 제어 권한을 확인합니다. 삭제되었거나 유효하지 않은 원본 메시지의 작업은 건너뜁니다.
