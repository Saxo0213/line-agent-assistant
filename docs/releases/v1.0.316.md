# v1.0.316 — changes since v1.0.314

## 繁體中文

Windows x64 版本。可透過 App「檢查更新」安裝；手動安裝檔、免安裝版、`SHA256SUMS.txt`、`latest.yml` 與 `.blockmap` 位於 [GitHub v1.0.316 Release](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.316)。本版包含本機 v1.0.315 的附件功能與 v1.0.316 更新流程修正：

- **群組與多人聊天室附件：** 系統完整附件備份仍保存在主要儲存區，並作為第二份複製來源；暫存資料夾是可選副本，不能取代主要備份。群組與多人聊天室在主要儲存區及暫存資料夾都依發言者／日期時間與訊息／附件／原始檔名分類，不新增獨立年月層。個人對話沿用原有主要儲存配置，也可選擇建立暫存複本。
- **暫存資料夾：** 僅 Primary Admin 可在目前聊天室使用 `/folder temp <existing absolute localdir>` 設定已存在的絕對本機資料夾、裸 `/folder temp` 查看、`/folder temp off` 關閉，或 `/folder temp retry` 重試。設定或更換後，背景作業會從本機備份複製該聊天室已下載且仍存在的附件；重試也從本機備份複製，不會重新向 LINE 下載。
- **已儲存檔案清單：** 聊天標題列中緊鄰「相片」左側的資料夾按鈕可開啟本機檔案表格；群組與多人聊天室項目另有發言者欄。
- **更新通知與版本同步：** 更新提示以左下角浮動通知顯示，不占用配置列。安裝器重啟後若執行版本與預定目標完全一致，會顯示「已安裝 v{版本}」及「詳細資訊」；Main 開啟相符且受信任的 Release 網址，並成功開啟及持久保存確認後，通知與 About 頁更新列才會消失。開啟瀏覽器或保存確認失敗時，通知會保留。`!` 與「更新」只適用於嚴格較新的安裝目標；若執行版本已與目標相同，會清除過期更新。下載進度、忽略版本與錯誤流程仍可使用；忽略版本、目標網址、通知與確認會持久保存，下載進度本身不跨重新啟動保存。

## English

Windows x64 release. Install through **Check for updates** in the app, or download the installer, portable build, `SHA256SUMS.txt`, `latest.yml`, and `.blockmap` from the [GitHub v1.0.316 release](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.316). This release includes the attachment features first shipped locally in v1.0.315 and v1.0.316 updater fixes:

- **Group and room attachments:** The system's complete attachment backup remains in primary storage and is the source for secondary copies; a temporary folder is optional and cannot replace the primary backup. Group and room attachments in both locations are organized by sender / date-time and message / attachment / original filename, without a separate year/month layer. Personal chats keep their existing primary layout; a personal chat can also have a temporary copy.
- **Temporary folders:** Only the Primary Admin can use `/folder temp <existing absolute localdir>` in the current chat to set an existing absolute local directory, bare `/folder temp` to view it, `/folder temp off` to disable it, and `/folder temp retry` to retry. Setting or changing it queues copies of that chat's already-downloaded attachments that still exist in the local backup. Retry also copies from the local backup and does not download again from LINE.
- **Stored-file list:** The folder button immediately left of Photos in the chat header opens a local file table. Group and room rows include an additional sender column.
- **Update notice and version reconciliation:** The notice floats at bottom-left without reserving a layout row. After installer restart, an exact match between the running version and intended target shows **Installed v{version}** and **Details**. Main opens the matching trusted release URL; the notice and About-page update row disappear only after the URL opens successfully and acknowledgement is durably saved. A browser-open or save failure keeps the notice. `!` and **Update** apply only to a strictly newer installer target; if the running version already equals the target, stale update state is cleared. Download progress, ignored-version, and error flows remain available. Ignored version, target URL, notice, and acknowledgement are durable; download progress itself is not persisted across restart.

## 日本語

Windows x64 版です。アプリの「更新を確認」から更新できます。手動インストーラー、ポータブル版、`SHA256SUMS.txt`、`latest.yml`、`.blockmap` は[GitHub v1.0.316 リリース](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.316)から取得できます。本版にはローカル v1.0.315 で先行した添付機能と、v1.0.316 の更新処理修正が含まれます。

- **グループとルームの添付ファイル：** システムの完全な添付バックアップはプライマリ保存先に残り、第二コピーの元になります。一時フォルダーは任意のコピーで、プライマリバックアップの代わりにはなりません。両方の保存先で、グループとルームの添付ファイルを送信者／日時とメッセージ／添付ファイル／元のファイル名で分類し、別の年・月階層は追加しません。個人チャットは従来のプライマリ構成を維持し、一時コピーも作成できます。
- **一時フォルダー：** Primary Admin のみが現在のチャットで `/folder temp <existing absolute localdir>` を使って既存の絶対ローカルフォルダーを設定し、裸の `/folder temp` で確認、`/folder temp off` で無効化、`/folder temp retry` で再試行できます。設定または変更すると、ローカルバックアップに残っているそのチャットのダウンロード済み添付ファイルをバックグラウンドでコピーします。再試行もローカルバックアップからコピーし、LINE から再ダウンロードしません。
- **保存ファイル一覧：** チャットヘッダーで「写真」のすぐ左にあるフォルダーボタンからローカルのファイル一覧表を開けます。グループとルームの行には送信者列が追加されます。
- **更新通知とバージョン照合：** 通知はレイアウト行を占有しない左下のフローティング表示です。インストーラー再起動後、実行中のバージョンが予定された対象と完全一致すると「v{version} をインストールしました」と「詳細」を表示します。Main が一致する信頼済み Release URL を開き、開く処理と確認の永続保存が成功した後に通知と About ページの更新行を消します。ブラウザー起動または保存に失敗した場合は通知を維持します。`!` と「更新」は厳密に新しいインストール対象だけに適用し、実行中のバージョンが対象と一致する場合は古い更新状態を消去します。ダウンロード進捗、無視設定、エラー処理は引き続き利用できます。無視したバージョン、対象 URL、通知、確認は永続化されますが、ダウンロード進捗自体は再起動後に保存されません。

## 한국어

Windows x64 버전입니다. 앱의 '업데이트 확인'으로 업데이트할 수 있습니다. 수동 설치 파일, 포터블 빌드, `SHA256SUMS.txt`, `latest.yml`, `.blockmap`은 [GitHub v1.0.316 릴리스](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.316)에서 받을 수 있습니다. 로컬 v1.0.315에서 먼저 제공된 첨부 파일 기능과 v1.0.316 업데이트 수정 사항을 포함합니다.

- **그룹 및 룸 첨부 파일:** 시스템 전체 첨부 백업은 기본 저장소에 계속 보관되며 보조 복사본의 원본입니다. 임시 폴더는 선택 복사본이며 기본 백업을 대체할 수 없습니다. 그룹 및 룸 첨부 파일은 두 위치 모두에서 발신자 / 날짜·시간 및 메시지 / 첨부 파일 / 원래 파일 이름으로 분류하고 별도의 연도/월 경로를 만들지 않습니다. 개인 대화는 기존 기본 구성을 유지하며 임시 복사본도 만들 수 있습니다.
- **임시 폴더:** Primary Admin만 현재 채팅에서 `/folder temp <existing absolute localdir>`로 기존 절대 로컬 폴더를 설정하고, `/folder temp`만 입력해 확인, `/folder temp off`로 끄기, `/folder temp retry`로 재시도할 수 있습니다. 설정 또는 변경 시 로컬 백업에 남아 있는 해당 채팅의 다운로드 완료 첨부 파일을 백그라운드에서 복사합니다. 재시도도 로컬 백업에서 복사하며 LINE에서 다시 다운로드하지 않습니다.
- **저장 파일 목록:** 채팅 헤더에서 Photos 바로 왼쪽의 폴더 버튼을 누르면 로컬 파일 표가 열립니다. 그룹 및 룸 항목에는 발신자 열이 추가됩니다.
- **업데이트 알림과 버전 확인:** 알림은 레이아웃 행을 차지하지 않는 왼쪽 아래 플로팅 표시입니다. 설치 프로그램 재시작 후 실행 중인 버전과 목표 버전이 정확히 일치하면 **v{version} 설치 완료**와 **자세히**를 표시합니다. Main이 일치하는 신뢰된 Release URL을 열고 확인 상태를 영구 저장해야 알림과 About 페이지 업데이트 행이 사라집니다. 브라우저 열기 또는 저장에 실패하면 알림을 유지합니다. `!`와 **업데이트**는 엄격히 더 새로운 설치 대상에만 적용하며 실행 버전이 목표와 같으면 오래된 업데이트 상태를 지웁니다. 다운로드 진행률, 무시, 오류 흐름은 계속 사용할 수 있습니다. 무시한 버전, 대상 URL, 알림 및 확인 상태는 저장되지만 다운로드 진행률 자체는 재시작 후 보존되지 않습니다.
