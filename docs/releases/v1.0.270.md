# v1.0.270 — changes since v1.0.261

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE.Agent.Assistant-1.0.270-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.270.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。

相較於上一個公開版本 [v1.0.261](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.261)：

- Agent 與管理者使用固定角色旗標，旗標對應目前帳號記錄；更換帳號編號不會改變該角色使用的功能與 MCP 權限。
- 帳號清單依固定角色顯示，移除已淘汰 Agent 帳號的歷史項目；好友確認會核對管理者與目標好友的實際關係。
- 搜尋結果保留完整帳號範圍；開啟結果時會導向該筆訊息所屬的正確對話。
- 修正新增好友請求的 LINE 欄位，並保留伺服器拒絕、附件下載及投票操作的錯誤細節，讓介面與診斷可呈現實際失敗原因。
- 強化登出完成判定與 Token 更新流程，避免工作階段狀態在登出或更新期間錯誤轉換。
- 本程式仍為非官方專案，與 LINE 無隸屬、背書或贊助關係。

## English

Windows x64 release. Download `LINE.Agent.Assistant-1.0.270-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.270.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`.

Changes since the previous public release, [v1.0.261](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.261):

- The Agent and administrator use fixed role flags that correspond to the current account records. Changing an account ID does not change the functions or MCP permissions used by that role.
- Account lists now show the fixed roles and omit retired Agent-account entries. Friend confirmation checks the actual relationship between the administrator and the target friend.
- Search results retain the full account scope, and opening a result navigates to the conversation that owns that message.
- Corrected LINE request fields for adding a friend and preserved server rejection, attachment download, and poll operation errors so the interface and diagnostics can show the failure details.
- Hardened logout completion checks and token refresh handling to prevent incorrect session state changes during logout or refresh.
- This remains an unofficial project and is not affiliated with, endorsed by, or sponsored by LINE or its affiliates.

## 日本語

Windows x64 版です。**Assets** から `LINE.Agent.Assistant-1.0.270-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.270.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。

前回の公開版 [v1.0.261](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.261) からの変更点：

- Agent と管理者は固定の役割フラグを使用し、各フラグは現在のアカウント記録に対応します。アカウント ID を変更しても、その役割が使う機能と MCP 権限は変わりません。
- アカウント一覧には固定された役割を表示し、廃止された Agent アカウントの履歴を除外します。友だち確認では、管理者と対象の友だちとの実際の関係を確認します。
- 検索結果はアカウント全体の範囲を保持し、結果を開くと該当メッセージが属する会話に移動します。
- 友だち追加時の LINE リクエスト項目を修正し、サーバーによる拒否、添付ファイルのダウンロード、投票操作のエラー情報を保持します。画面と診断情報から実際の失敗内容を確認できます。
- ログアウト完了の判定とトークン更新を強化し、ログアウトや更新中にセッション状態が誤って切り替わらないようにしました。
- 本アプリは引き続き非公式プロジェクトであり、LINE およびその関連会社とは提携・承認・支援関係にありません。

## 한국어

Windows x64 버전입니다. **Assets**에서 `LINE.Agent.Assistant-1.0.270-Setup-x64.exe`를 다운로드하세요. `LINE-Agent-Assistant-1.0.270.zip`은 포터블 버전입니다. SHA-256 값은 `SHA256SUMS.txt`에 있습니다.

이전 공개 버전 [v1.0.261](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.261) 이후 변경 사항:

- Agent와 관리자는 고정 역할 플래그를 사용하며, 각 플래그는 현재 계정 기록에 대응합니다. 계정 ID를 변경해도 해당 역할이 사용하는 기능과 MCP 권한은 바뀌지 않습니다.
- 계정 목록은 고정된 역할을 표시하고 폐기된 Agent 계정의 과거 항목을 제외합니다. 친구 확인은 관리자와 대상 친구 사이의 실제 관계를 확인합니다.
- 검색 결과는 전체 계정 범위를 유지하며, 결과를 열면 해당 메시지가 속한 대화로 이동합니다.
- 친구 추가를 위한 LINE 요청 필드를 수정하고 서버 거부, 첨부 파일 다운로드, 투표 작업의 오류 정보를 보존해 화면과 진단에서 실제 실패 내용을 확인할 수 있습니다.
- 로그아웃 완료 판정과 토큰 갱신 처리를 강화해 로그아웃 또는 갱신 중 세션 상태가 잘못 바뀌지 않도록 했습니다.
- 이 앱은 계속 비공식 프로젝트이며 LINE 또는 그 계열사와 제휴 관계가 없고, 이들의 승인이나 후원을 받지 않습니다.
