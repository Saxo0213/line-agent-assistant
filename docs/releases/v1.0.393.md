## 繁體中文

- **專案資料夾預設可讀取：** 「讀取專案資料夾」權限預設改為允許。白名單成員在管理者以 `/folder` 綁定專案資料夾的聊天室，可直接讓 Agent 讀取該資料夾。「寫入專案資料夾」仍預設拒絕。已個別設定的規則不受影響，也可在「設定 → 權限」改為拒絕。

## English

- **Project folder read by default:** The **Read project folder** permission now defaults to allow. In a chat where the administrator bound a project folder with `/folder`, the Agent can read that folder for a whitelisted member. **Write project folder** still defaults to deny. Existing per-member rules do not change, and you can set the permission to deny in **Settings → Permissions**.

## 日本語

- **プロジェクトフォルダーを既定で読み取り可能に：** 「プロジェクトフォルダーの読み取り」権限の既定値を許可に変更しました。管理者が `/folder` でプロジェクトフォルダーを紐付けたチャットでは、ホワイトリストのメンバーのために Agent がそのフォルダーを読み取れます。「プロジェクトフォルダーへの書き込み」は引き続き既定で拒否です。個別に設定済みのルールは変わらず、「設定 → 権限」で拒否に変更することもできます。

## 한국어

- **프로젝트 폴더 기본 읽기 허용:** '프로젝트 폴더 읽기' 권한의 기본값을 허용으로 바꿨습니다. 관리자가 `/folder`로 프로젝트 폴더를 연결한 채팅에서는 화이트리스트 멤버를 위해 Agent가 그 폴더를 읽을 수 있습니다. '프로젝트 폴더 쓰기'는 계속 기본 거부입니다. 개별로 설정한 규칙은 바뀌지 않으며, '설정 → 권한'에서 거부로 바꿀 수 있습니다.
