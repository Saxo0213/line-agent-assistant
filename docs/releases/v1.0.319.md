# v1.0.319 — changes since v1.0.318

## 繁體中文

Windows x64 版本。可透過 App「檢查更新」安裝；手動安裝檔與免安裝版請見 GitHub v1.0.319 Release。

- **Agent 排程工具的轉送規則參數範例：** 建立與更新工具會明確示範巢狀比對及發言者欄位（`task.match.mode`、`task.sender.mid`），協助 Agent 依正確結構建立或修改規則。
- **可操作的驗證錯誤：** 無效輸入會指出相關輸入路徑，協助 Agent 修正請求。實際驗證規則維持不變；既有排程也不會因此變更。
- **權威傳送帳號資訊：** `list_send_targets` 會回傳已授權的 Agent 傳送帳號 `accountId`；若沒有可用的授權帳號，則回傳 `null` 和空目標清單，避免 Agent 猜測帳號。

## English

Windows x64 release. Install through **Check for updates** in the app; the installer and portable build are available from the GitHub v1.0.319 release.

- **Explicit forwarding-rule parameter examples in Agent schedule tools:** Create and update tool descriptions show examples for the nested match and sender fields (`task.match.mode` and `task.sender.mid`) so the Agent can use the intended structure when creating or editing rules.
- **Actionable validation errors:** Invalid inputs identify the relevant input path to help the Agent correct its request. Actual validation rules are unchanged, and existing schedules are not modified.
- **Authoritative send-account information:** `list_send_targets` returns the `accountId` of the authorized Agent send account. If no authorized Agent account is available, it returns `null` and an empty target list so the Agent does not have to guess.

## 日本語

Windows x64 版です。アプリの「更新を確認」から更新できます。インストーラーとポータブル版は GitHub v1.0.319 リリースから入手できます。

- **Agent のスケジュールツールに転送ルールのパラメーター例を追加：** 作成・更新ツールの説明に、入れ子になった一致条件と送信者項目（`task.match.mode`、`task.sender.mid`）の例を示し、正しい形式でルールを作成・編集できるようにしました。
- **修正に役立つ検証エラー：** 無効な入力について、該当する入力パスを示し、Agent がリクエストを修正しやすくしました。実際の検証ルールは変更せず、既存のスケジュールも変更しません。
- **送信アカウント情報の明確化：** `list_send_targets` は、認可済み Agent 送信アカウントの `accountId` を返します。利用可能な認可済み Agent アカウントがない場合は、Agent が推測せずに済むよう `null` と空の宛先一覧を返します。

## 한국어

Windows x64 버전입니다. 앱의 '업데이트 확인'으로 설치할 수 있습니다. 설치 파일과 포터블 빌드는 GitHub v1.0.319 릴리스에서 받을 수 있습니다.

- **Agent 예약 도구의 전달 규칙 매개변수 예시:** 생성 및 업데이트 도구 설명에 중첩 일치 및 발신자 필드(`task.match.mode`, `task.sender.mid`) 예시를 표시해 Agent가 올바른 구조로 규칙을 만들고 수정할 수 있습니다.
- **조치 가능한 검증 오류:** 잘못된 입력에 대해 관련 입력 경로를 표시해 Agent가 요청을 바로잡도록 돕습니다. 실제 검증 규칙은 그대로이며 기존 예약도 변경되지 않습니다.
- **권한이 확인된 발신 계정 정보:** `list_send_targets`는 권한이 확인된 Agent 발신 계정의 `accountId`를 반환합니다. 사용할 수 있는 권한 있는 Agent 계정이 없으면 Agent가 계정을 추측하지 않도록 `null`과 빈 대상 목록을 반환합니다.
