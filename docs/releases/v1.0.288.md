# v1.0.288 — changes since v1.0.280

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE-Agent-Assistant-1.0.288-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.288.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。`latest.yml` 與 `.blockmap` 供 App 內自動更新使用；已安裝 v1.0.280 的使用者可直接在右下角提示選擇「更新」。

相較於上一個公開版本 [v1.0.280](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.280)：

- 群組自由模式改為兩階段：先由快速模型判斷是否需要回覆並評估急迫度，再由主模型回覆。最後一則訊息後安靜 3 秒或第一則訊息後 15 秒即開始處理；回覆進行中若有急迫度 70 以上的新訊息會中斷並重寫（每輪最多 2 次）。回覆失敗時會在群組通知一次。
- 新增 Agent 個性與回覆積極度（安靜／一般／活潑）：在「設定 → 助理」設定全域預設，主要管理者可在群組用 `/persona` 覆寫。個性影響自由模式的回覆判斷與所有 LINE 回覆的語氣。
- 新增 `/folder` 專案資料夾：主要管理者可把電腦上的資料夾綁定到聊天室（預設唯讀，`/folder rw` 可讀寫），讓 Agent 在該聊天室查詢資料。「設定 → 權限」新增「讀取／寫入專案資料夾」權限。系統、程式與 App 資料位置不可綁定。
- 所有 Agent 工作（含群組成員與自由模式）都可使用網路搜尋與開啟網頁。
- Agent 在群組回覆中寫 `@成員名稱` 時，會轉成 LINE 標註；名稱需與成員名稱完全相符且唯一。
- LINE 聊天改依「設定 → 助理」的預設 Agent。主要管理者可用 `/agent claude`、`/agent codex` 固定單一聊天室的模型，`/agent default` 還原。群組成員權限無法執行 Codex 時自動改用 Claude。
- 主要管理者在群組輸入 `@Agent 監控` 或 `/free` 會直接啟用該群組，不再需要確認碼；其他人申請時，私訊給管理者的確認訊息顯示聊天室名稱。
- `/stop`、`/new` 與各管理指令都會回覆確認；非主要管理者輸入管理指令時不執行，視為一般訊息。
- 「設定 → 助理」新增 Agent 擴充工具：可匯入本機已設定的 MCP 伺服器、手動新增 MCP，並調整 Claude 內建工具，供 Agent 房、排程與主要管理者使用。
- 「設定 → 指令」改為分類列出所有 LINE 指令與用途。
- 本程式仍為非官方專案，與 LINE 無隸屬、背書或贊助關係。

## English

Windows x64 release. Download `LINE-Agent-Assistant-1.0.288-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.288.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`. `latest.yml` and the `.blockmap` are used by the in-app updater; if v1.0.280 is installed, choose Update in the bottom-right prompt.

Changes since the previous public release, [v1.0.280](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.280):

- Group free mode now works in two stages: a fast model decides whether to reply and rates urgency, then the main model writes the reply. Processing starts after 3 seconds of quiet or 15 seconds after the first message. A new message with urgency 70 or more interrupts and rewrites a reply in progress (at most twice per round). A failed reply is reported once in the group.
- New Agent persona and reply liveliness (quiet, normal, lively): set the global default in Settings → Assistant, and the Primary Admin can override it per group with `/persona`. The persona affects free-mode reply decisions and the tone of all LINE replies.
- New `/folder` project folders: the Primary Admin can bind a folder on this computer to a chat (read-only by default, `/folder rw` for read-write) so the Agent can look things up there. Settings → Permissions adds Read and Write project folder permissions. System, program, and app data locations cannot be bound.
- Every Agent job, including group members and free mode, can use web search and open web pages.
- When the Agent writes `@member name` in a group reply, it becomes a LINE mention. The name must match exactly one member.
- LINE chats now follow the default Agent in Settings → Assistant. The Primary Admin can pin one chat's model with `/agent claude` or `/agent codex`, and `/agent default` restores it. When group-member permissions cannot run Codex, Claude is used instead.
- In a group, the Primary Admin's `@Agent monitor` or `/free` enables the group directly without a confirmation code. When someone else requests activation, the admin's direct message shows the chat name.
- `/stop`, `/new`, and the management commands now reply with a confirmation. Management commands from anyone other than the Primary Admin are not executed and are treated as ordinary messages.
- Settings → Assistant adds Agent extension tools: import locally configured MCP servers, add MCP servers manually, and adjust Claude built-in tools for the Agent room, schedules, and the Primary Admin.
- Settings → Commands now lists every LINE command and its purpose by category.
- This remains an unofficial project and is not affiliated with, endorsed by, or sponsored by LINE or its affiliates.

## 日本語

Windows x64 版です。**Assets** から `LINE-Agent-Assistant-1.0.288-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.288.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。`latest.yml` と `.blockmap` はアプリ内の自動更新で使用します。v1.0.280 をお使いの場合は、右下の通知で「更新」を選べます。

前回の公開版 [v1.0.280](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.280) からの変更点：

- グループのフリーモードを 2 段階にしました。高速モデルが返信の要否と緊急度を判定し、メインモデルが返信します。最後のメッセージから 3 秒静かになるか、最初のメッセージから 15 秒で処理を始めます。返信中に緊急度 70 以上の新しいメッセージが来ると中断して書き直します（1 ラウンド最大 2 回）。返信に失敗した場合はグループに 1 回通知します。
- Agent の個性と返信の積極度（控えめ／普通／活発）を追加しました。「設定 → アシスタント」で全体の既定値を設定し、プライマリ管理者はグループごとに `/persona` で上書きできます。個性はフリーモードの返信判定とすべての LINE 返信の口調に反映されます。
- `/folder` によるプロジェクトフォルダーを追加しました。プライマリ管理者はこのコンピューター上のフォルダーをトークに割り当てられ（既定は読み取り専用、`/folder rw` で読み書き可）、Agent がそのトークで資料を調べられます。「設定 → 権限」に「プロジェクトフォルダーの読み取り／書き込み」を追加しました。システム、プログラム、アプリのデータの場所は割り当てできません。
- グループメンバーやフリーモードを含むすべての Agent ジョブで、ウェブ検索とウェブページの閲覧が使えます。
- Agent がグループの返信で `@メンバー名` と書くと、LINE のメンションになります。名前は 1 人のメンバーと完全に一致する必要があります。
- LINE のトークは「設定 → アシスタント」の既定 Agent に従います。プライマリ管理者は `/agent claude`、`/agent codex` で 1 つのトークのモデルを固定でき、`/agent default` で元に戻せます。グループメンバーの権限で Codex を実行できない場合は Claude を使います。
- グループでプライマリ管理者が `@Agent 監控`（または `@Agent monitor`）や `/free` を送ると、確認コードなしでグループを有効にします。他の人が申請した場合、管理者への個別メッセージにトーク名を表示します。
- `/stop`、`/new` と各管理コマンドは確認の返信をします。プライマリ管理者以外が管理コマンドを送っても実行せず、通常のメッセージとして扱います。
- 「設定 → アシスタント」に Agent 拡張ツールを追加しました。ローカルで設定済みの MCP サーバーの取り込み、MCP サーバーの手動追加、Claude 組み込みツールの調整ができ、Agent ルーム、スケジュール、プライマリ管理者が使用します。
- 「設定 → コマンド」で、すべての LINE コマンドと用途を分類して一覧表示します。
- 本アプリは引き続き非公式プロジェクトであり、LINE およびその関連会社とは提携・承認・支援関係にありません。

## 한국어

Windows x64 버전입니다. **Assets**에서 `LINE-Agent-Assistant-1.0.288-Setup-x64.exe`를 다운로드하세요. `LINE-Agent-Assistant-1.0.288.zip`은 포터블 버전입니다. SHA-256 값은 `SHA256SUMS.txt`에 있습니다. `latest.yml`과 `.blockmap`은 앱 내 자동 업데이트에 사용됩니다. v1.0.280을 사용 중이면 오른쪽 아래 알림에서 '업데이트'를 선택하면 됩니다.

이전 공개 버전 [v1.0.280](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.280) 이후 변경 사항:

- 그룹 자유 모드를 두 단계로 바꿨습니다. 빠른 모델이 답장 여부와 긴급도를 판단하고, 주 모델이 답장을 작성합니다. 마지막 메시지 후 3초 동안 조용하거나 첫 메시지 후 15초가 지나면 처리를 시작합니다. 답장 중에 긴급도 70 이상의 새 메시지가 오면 중단하고 다시 작성합니다(라운드당 최대 2회). 답장에 실패하면 그룹에 한 번 알립니다.
- Agent 성격과 답장 적극성(조용함/보통/활발함)을 추가했습니다. '설정 → 어시스턴트'에서 전체 기본값을 정하고, 기본 관리자는 그룹마다 `/persona`로 덮어쓸 수 있습니다. 성격은 자유 모드의 답장 판단과 모든 LINE 답장의 말투에 반영됩니다.
- `/folder` 프로젝트 폴더를 추가했습니다. 기본 관리자는 이 컴퓨터의 폴더를 채팅에 연결할 수 있으며(기본은 읽기 전용, `/folder rw`는 읽기/쓰기), Agent가 해당 채팅에서 자료를 찾아볼 수 있습니다. '설정 → 권한'에 '프로젝트 폴더 읽기/쓰기' 권한을 추가했습니다. 시스템, 프로그램, 앱 데이터 위치는 연결할 수 없습니다.
- 그룹 멤버와 자유 모드를 포함한 모든 Agent 작업에서 웹 검색과 웹 페이지 열기를 사용할 수 있습니다.
- Agent가 그룹 답장에 `@멤버 이름`을 쓰면 LINE 멘션으로 바뀝니다. 이름은 한 명의 멤버와 정확히 일치해야 합니다.
- LINE 채팅은 '설정 → 어시스턴트'의 기본 Agent를 따릅니다. 기본 관리자는 `/agent claude`, `/agent codex`로 한 채팅의 모델을 고정하고 `/agent default`로 되돌릴 수 있습니다. 그룹 멤버 권한으로 Codex를 실행할 수 없으면 Claude를 사용합니다.
- 그룹에서 기본 관리자가 `@Agent 監控`(또는 `@Agent monitor`)나 `/free`를 보내면 확인 코드 없이 그룹을 바로 활성화합니다. 다른 사람이 요청하면 관리자에게 보내는 개인 메시지에 채팅 이름을 표시합니다.
- `/stop`, `/new`와 관리 명령은 확인 답장을 보냅니다. 기본 관리자가 아닌 사람이 보낸 관리 명령은 실행하지 않고 일반 메시지로 처리합니다.
- '설정 → 어시스턴트'에 Agent 확장 도구를 추가했습니다. 로컬에 설정된 MCP 서버 가져오기, MCP 서버 직접 추가, Claude 기본 제공 도구 조정이 가능하며 Agent 룸, 예약, 기본 관리자가 사용합니다.
- '설정 → 명령'에서 모든 LINE 명령과 용도를 분류해 보여 줍니다.
- 이 앱은 계속 비공식 프로젝트이며 LINE 또는 그 계열사와 제휴 관계가 없고, 이들의 승인이나 후원을 받지 않습니다.
