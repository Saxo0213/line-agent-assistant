# v1.0.318 — changes since v1.0.316

## 繁體中文

Windows x64 版本。可透過 App「檢查更新」安裝；手動安裝檔與免安裝版請見 GitHub v1.0.318 Release。

- **監控訊息即時路由：** 監控完成第一輪基準後，只將新訊息送入 Agent 工作；啟動時匯入的舊訊息不會觸發。Agent 狀態可顯示在原管理員對話中。
- **事件訊息轉送：** 排程可設定事件規則，選擇來源聊天室、Agent 目的聊天室，以及包含關鍵字、完全相符或發言者條件。規則支援 App 與 MCP。
- **原文與附件：** 轉送使用原始文字及已下載的圖片、檔案，保留附件順序與檔名；影片與音訊以檔案傳送。尚未下載的附件會等待；不支援的內容會標示，不會要求 AI 重新摘要或改寫原文。
- **逐項結果與復原：** 每個轉送項目會保存各部分的結果。部分成功會保留已完成部分；結果不明的傳送不會自動重試，避免重複傳送。

## English

Windows x64 release. Install through **Check for updates** in the app; the installer and portable build are available from the GitHub v1.0.318 release.

- **Prompt monitored-message routing:** After the first complete monitoring round establishes a baseline, only fresh messages enter Agent work. Messages encountered during startup import do not trigger work. Agent status can appear on the original administrator conversation.
- **Event message forwarding:** Schedule event rules can select source chats, an Agent destination chat, and contains-keyword, exact-text, or sender matching. The feature is available through both the app and MCP.
- **Original text and attachments:** Forwarding uses the original text and downloaded images and files, preserving attachment order and filenames. Video and audio are sent as files. Undownloaded attachments wait for readiness; unsupported content is recorded as such. The original is not sent to AI for summarization or rewriting.
- **Per-part outcomes and recovery:** Each forwarding item stores the outcome of every part. Partial success preserves completed parts; a send with an unknown outcome is not retried automatically, preventing duplicate sends.

## 日本語

Windows x64 版です。アプリの「更新を確認」から更新できます。インストーラーとポータブル版は GitHub v1.0.318 リリースから入手できます。

- **監視メッセージの迅速なルーティング：** 最初の監視ラウンドで基準を確立した後、新着メッセージのみを Agent タスクに渡します。起動時の履歴取り込みではタスクを開始しません。Agent の状態を元の管理者チャットに表示できます。
- **イベントメッセージ転送：** スケジュールのイベントルールで、送信元チャット、Agent の転送先、キーワードを含む条件、完全一致、送信者条件を設定できます。アプリと MCP の両方で利用できます。
- **元のテキストと添付ファイル：** 元のテキストとダウンロード済みの画像・ファイルを使い、添付ファイルの順序とファイル名を保ちます。動画と音声はファイルとして送信します。未ダウンロードの添付ファイルは準備完了を待ち、未対応の内容はその状態を記録します。AI による要約や書き換えは行いません。
- **項目ごとの結果と復旧：** 各転送項目はパーツごとの結果を保存します。一部が成功した場合は完了分を保持し、結果不明の送信は重複防止のため自動再試行しません。

## 한국어

Windows x64 버전입니다. 앱의 '업데이트 확인'으로 설치할 수 있습니다. 설치 파일과 포터블 빌드는 GitHub v1.0.318 릴리스에서 받을 수 있습니다.

- **모니터링 메시지 신속 라우팅:** 첫 모니터링 라운드가 기준점을 설정한 뒤 새 메시지만 Agent 작업으로 전달합니다. 시작 시 가져오는 기록은 작업을 시작하지 않습니다. Agent 상태를 원래 관리자 대화에 표시할 수 있습니다.
- **이벤트 메시지 전달:** 스케줄 이벤트 규칙에서 소스 채팅, Agent 대상 채팅, 키워드 포함, 정확한 텍스트, 발신자 조건을 설정할 수 있습니다. 앱과 MCP 모두에서 사용할 수 있습니다.
- **원문과 첨부 파일:** 원본 텍스트와 다운로드된 이미지 및 파일을 사용하며 첨부 순서와 파일 이름을 보존합니다. 동영상과 오디오는 파일로 전송합니다. 아직 다운로드되지 않은 첨부 파일은 준비될 때까지 기다리고 지원되지 않는 콘텐츠는 해당 상태로 기록합니다. AI 요약이나 재작성은 하지 않습니다.
- **항목별 결과와 복구:** 각 전달 항목은 부분별 결과를 저장합니다. 일부가 성공하면 완료된 부분을 유지하고, 결과가 불명확한 전송은 중복 방지를 위해 자동 재시도하지 않습니다.
