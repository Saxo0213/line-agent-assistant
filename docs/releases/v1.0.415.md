## 繁體中文

- **Agent Skill 修正：** v1.0.404 起 Agent 的 LINEJS Skill 超過大小上限而沒有載入，造成 Agent 回答品質下降；本版已修正，Skill 改寫為簡明英文規則，Agent 依使用者的語言回覆（預設繁體中文）。
- **成員回覆稽核：** 每個 LINE 工作會告知 Agent 發問者是主要管理者還是成員；App 版本、設定、資料夾、權限、工具、其他聊天室與排程等系統資訊只回答主要管理者。成員觸發的 Agent 回覆送出前，會先比對特徵（版本號、路徑、工具名、ID）並由一次性的稽核模型判斷；判定不宜時改送「此項由管理者管理。」，系統紀錄顯示「Agent 回覆稽核」。
- **聊天室規則：** 主要管理者可在群組或聊天室輸入 `/rules` 查看或設定該聊天室的 Agent 規則：`/rules <內容>` 設定基本規則，`/rules add <名稱> <內容>` 新增分檔規則，`/rules remove <名稱>`、`/rules clear` 移除。規則存在聊天室資料夾的 `AGENTS.md`（`CLAUDE.md` 指向它）；Agent 工作中改動的規則檔會在工作結束時還原，並寫入系統紀錄。
- **外部 Agent 等候管理者回覆：** Claude Code、Codex 等外部 MCP 工具傳給主要管理者的訊息會加上【標籤 #n】；管理者在 LINE 引用回覆即直接轉回該外部工具（`wait_for_admin_reply`、`list_admin_replies`、`close_session`）。管理者未引用時，Agent 可依等候清單把訊息轉給指定的外部工具。
- **`/help`：** 主要管理者在與 Agent 的 1:1 輸入 `/help`、`/說明` 或 `/指令`，會依類別列出所有 LINE 指令。
- **傳送檔案與路徑：** Agent 可直接傳送專案資料夾內的檔案；傳到 LINE 的文字會以標籤取代 App 的本機路徑。LINE 指令的回覆改為直接說明動作或結果。
- **長截圖：** 很長的手機截圖可以預覽；聊天中過高的圖片顯示上半部，「開啟」可看完整圖片。
- **修正：** 自由模式的稽核紀錄過去無法寫入，本版已修正。

## English

- **Agent Skill fix:** From v1.0.404 the LINEJS Skill of the Agent was over the size limit and did not load, so Agent answers were worse. This version fixes it. The Skill is rewritten as short English rules, and the Agent replies in the user's language (default Traditional Chinese).
- **Member reply audit:** Each LINE job tells the Agent whether the requester is the Primary Admin or a member. System information (app version, settings, folders, permissions, tools, other chats, schedules) is for the Primary Admin only. Before an Agent reply to a member goes out, it is checked for patterns (version, paths, tool names, ids) and by a one-shot audit model. A blocked reply goes out as 「此項由管理者管理。」, and the system records show 「Agent 回覆稽核」.
- **Chat rules:** In a group or room, the Primary Admin types `/rules` to show or set the Agent rules of that chat: `/rules <text>` sets the base rules, `/rules add <name> <text>` adds a rule file, and `/rules remove <name>` and `/rules clear` remove them. The rules are in `AGENTS.md` in the chat folder (`CLAUDE.md` points to it). A rules file changed during an Agent job is restored when the job ends, with a system record.
- **External agents wait for the admin:** Messages that Claude Code, Codex or another external MCP client sends to the Primary Admin get a 【label #n】 tag. A quoted reply of the admin in LINE goes straight back to that client (`wait_for_admin_reply`, `list_admin_replies`, `close_session`). When the admin does not quote, the Agent can forward the message to a waiting client from its list.
- **`/help`:** In the 1:1 chat with the Agent, `/help`, `/說明` or `/指令` from the Primary Admin lists all LINE commands by category.
- **Files and paths:** The Agent sends files from project folders directly. Text sent to LINE shows labels instead of the app's local paths. LINE command replies state the action or result directly.
- **Long screenshots:** Very tall phone screenshots now preview. A very tall image in the chat shows its top; **Open** shows the full image.
- **Fix:** Free-mode audit records were not written before. This version fixes it.

## 日本語

- **Agent Skill の修正：** v1.0.404 から Agent の LINEJS Skill がサイズ上限を超えて読み込まれず、Agent の回答品質が下がっていました。本バージョンで修正しました。Skill は簡潔な英語のルールに書き直し、Agent はユーザーの言語で返信します（既定は繁体字中国語）。
- **メンバーへの返信の審査：** 各 LINE ジョブで、質問者がメイン管理者かメンバーかを Agent に伝えます。アプリのバージョン、設定、フォルダー、権限、ツール、他のトーク、スケジュールなどのシステム情報はメイン管理者にのみ答えます。メンバーへの Agent の返信は送信前にパターン（バージョン、パス、ツール名、ID）の照合と一度だけの審査モデルで確認し、不適切と判断した場合は「此項由管理者管理。」を送ります。システム記録には「Agent 回覆稽核」と表示されます。
- **トークのルール：** メイン管理者はグループまたはルームで `/rules` を入力して、そのトークの Agent ルールを表示・設定できます。`/rules <内容>` で基本ルール、`/rules add <名前> <内容>` で分割ルールを追加し、`/rules remove <名前>`、`/rules clear` で削除します。ルールはトークフォルダーの `AGENTS.md`（`CLAUDE.md` はこれを参照）に保存されます。Agent のジョブ中に変更されたルールファイルはジョブ終了時に元に戻り、システム記録に残ります。
- **外部 Agent が管理者の返信を待つ：** Claude Code、Codex などの外部 MCP クライアントがメイン管理者に送るメッセージには【ラベル #n】が付きます。管理者が LINE で引用返信すると、そのクライアントに直接返ります（`wait_for_admin_reply`、`list_admin_replies`、`close_session`）。引用しない場合は、Agent が待機リストから指定のクライアントに転送できます。
- **`/help`：** Agent との 1:1 でメイン管理者が `/help`、`/說明`、`/指令` を入力すると、すべての LINE コマンドをカテゴリ別に表示します。
- **ファイルとパス：** Agent はプロジェクトフォルダー内のファイルを直接送信します。LINE に送るテキストでは、アプリのローカルパスをラベルに置き換えます。LINE コマンドの返信は操作や結果を直接伝えるようにしました。
- **長いスクリーンショット：** 非常に縦長のスマートフォンのスクリーンショットをプレビューできます。トーク内の縦長の画像は上部を表示し、「開く」で全体を表示します。
- **修正：** フリーモードの監査記録が書き込まれなかった問題を修正しました。

## 한국어

- **Agent Skill 수정:** v1.0.404부터 Agent의 LINEJS Skill이 크기 제한을 넘어 로드되지 않아 Agent 답변 품질이 떨어졌습니다. 이번 버전에서 수정했습니다. Skill은 간결한 영어 규칙으로 다시 작성했으며, Agent는 사용자의 언어로 답합니다(기본값 번체 중국어).
- **멤버 답변 심사:** 각 LINE 작업에서 질문자가 주 관리자인지 멤버인지 Agent에 알려 줍니다. 앱 버전, 설정, 폴더, 권한, 도구, 다른 채팅, 일정 등 시스템 정보는 주 관리자에게만 답합니다. 멤버에게 보내는 Agent 답변은 전송 전에 패턴(버전, 경로, 도구 이름, ID) 대조와 일회성 심사 모델로 확인하며, 부적절하다고 판단하면 「此項由管理者管理。」를 보냅니다. 시스템 기록에는 「Agent 回覆稽核」으로 표시됩니다.
- **채팅 규칙:** 주 관리자는 그룹 또는 룸에서 `/rules`를 입력해 그 채팅의 Agent 규칙을 보거나 설정할 수 있습니다. `/rules <내용>`은 기본 규칙, `/rules add <이름> <내용>`은 분할 규칙 추가, `/rules remove <이름>`, `/rules clear`는 삭제입니다. 규칙은 채팅 폴더의 `AGENTS.md`(`CLAUDE.md`가 이를 가리킴)에 저장됩니다. Agent 작업 중 바뀐 규칙 파일은 작업이 끝날 때 복원되며 시스템 기록에 남습니다.
- **외부 Agent가 관리자 답변을 기다림:** Claude Code, Codex 등 외부 MCP 클라이언트가 주 관리자에게 보내는 메시지에는 【라벨 #n】이 붙습니다. 관리자가 LINE에서 인용 답장하면 그 클라이언트로 바로 돌아갑니다(`wait_for_admin_reply`, `list_admin_replies`, `close_session`). 인용하지 않으면 Agent가 대기 목록에서 지정한 클라이언트로 전달할 수 있습니다.
- **`/help`:** Agent와의 1:1에서 주 관리자가 `/help`, `/說明`, `/指令`을 입력하면 모든 LINE 명령을 분류별로 보여 줍니다.
- **파일과 경로:** Agent는 프로젝트 폴더의 파일을 바로 보냅니다. LINE으로 보내는 텍스트에서는 앱의 로컬 경로를 라벨로 바꿉니다. LINE 명령 답변은 동작이나 결과를 바로 알려 줍니다.
- **긴 스크린샷:** 매우 긴 휴대폰 스크린샷을 미리 볼 수 있습니다. 채팅의 매우 긴 이미지는 윗부분을 보여 주며, '열기'로 전체를 볼 수 있습니다.
- **수정:** 자유 모드의 감사 기록이 기록되지 않던 문제를 수정했습니다.
