# v1.0.302 — changes since v1.0.288

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE-Agent-Assistant-1.0.302-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.302.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。`latest.yml` 與 `.blockmap` 供 App 內自動更新使用；已安裝 v1.0.288 的使用者可直接在右下角提示選擇「更新」。

相較於上一個公開版本 [v1.0.288](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.288)：

- 修正 Agent 傳送圖片與檔案一律失敗（上傳時 HTTP 411）。
- 傳送失敗時保留實際原因：worker 錯誤碼、上傳階段與伺服器回應，不再只顯示「傳送失敗」。
- 登入：登入失敗時記錄診斷資訊；QR 登入失敗後帳號回到登出狀態；取消已知帳號的 QR 登入時，保留原有登入資料，也不會對伺服器登出。
- 外部監控改為官方 LINE 資料庫一有變動就讀取（原為每 5 秒輪詢），訊息與收回較不易遺漏原文。
- 外部監控的附件無法下載時，附件卡片會顯示原因。
- 聊天清單的通話紀錄改為顯示本地化文字。
- `/adduser` 不再要求對方先成為 Agent 的 LINE 好友；TOKEN 驗證通過即加入白名單。登入時也不再檢查主要管理者的好友關係。
- Agent 的 LINE 回覆須為完整句子；資訊不足時會先問清楚，不再只送出半句。
- 執行等級為「完全存取」且允許本機工具時，LINE 聊天中的 Agent 工作可使用 Bash、網路搜尋與開啟網頁。
- 新增本機發送紀錄：對 LINE 主機的每個 HTTP 請求記錄於 App 資料夾的 `logs\line-traffic`（不含訊息內容），保留 14 天或 200 MB。
- 主要管理者的登入按鈕改名；外部監控執行中不能按管理者登入。
- 調整幾個對話框的按鈕列與勾選框排版。
- **實驗功能（目前無法使用）**：QR 登入與帳號卡片新增「Chrome 版」登入方式，需要本機安裝 LINE Chrome 擴充功能 3.7.2。此方式尚未完成，無法正常連線，請繼續使用預設的 Windows 版。
- 本程式仍為非官方專案，與 LINE 無隸屬、背書或贊助關係。

## English

Windows x64 release. Download `LINE-Agent-Assistant-1.0.302-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.302.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`. `latest.yml` and the `.blockmap` are used by the in-app updater; if v1.0.288 is installed, choose Update in the bottom-right prompt.

Changes since the previous public release, [v1.0.288](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.288):

- Fixed: every Agent image and file send failed (HTTP 411 on upload).
- A failed send keeps its real cause (worker error code, upload stage, and server reason) instead of a generic send failure.
- Login: a failed login records diagnostics; a failed QR login leaves the account logged out; cancelling the QR login of a known account keeps its saved login and sends no server logout.
- External Monitor reads the official LINE database as soon as it changes (before: every 5 seconds), so messages and the original text of recalled messages are missed less often.
- When an External Monitor attachment cannot download, the attachment card shows why.
- Call history in the chat list shows localized text.
- `/adduser` no longer requires the person to be a LINE friend of the Agent; a correct TOKEN adds them to the allowlist. Login no longer checks the Primary Admin's friendship either.
- Agent replies in LINE must be complete sentences; when information is missing, the Agent asks for it instead of sending a fragment.
- At the Full access level with local tools allowed, Agent jobs in LINE chats can use Bash, web search, and web pages.
- New local send log: every HTTP request to LINE hosts is recorded in `logs\line-traffic` in the app data folder (no message content), kept for 14 days or 200 MB.
- The Primary Admin login buttons are renamed; the admin login button is disabled while External Monitor runs.
- Button rows and checkboxes in several dialogs are laid out better.
- **Experimental (does not work yet):** QR login and the account card add a "Chrome" login method that needs the LINE Chrome extension 3.7.2 installed locally. It is not finished and cannot connect; keep using the default Windows method.
- This remains an unofficial project and is not affiliated with, endorsed by, or sponsored by LINE or its affiliates.

## 日本語

Windows x64 版です。**Assets** から `LINE-Agent-Assistant-1.0.302-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.302.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。`latest.yml` と `.blockmap` はアプリ内の自動更新で使用します。v1.0.288 をお使いの場合は、右下の通知で「更新」を選べます。

前回の公開版 [v1.0.288](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.288) からの変更点：

- Agent の画像とファイルの送信がすべて失敗する問題（アップロード時の HTTP 411）を修正しました。
- 送信に失敗したとき、実際の原因（worker のエラーコード、アップロードの段階、サーバーの応答）を残します。
- ログイン：失敗時に診断情報を記録します。QR ログインに失敗するとアカウントはログアウト状態に戻ります。既知のアカウントの QR ログインを取り消しても、保存済みのログイン情報を残し、サーバーへのログアウトも送りません。
- 外部モニターは、公式 LINE のデータベースが変わるとすぐに読み取ります（以前は 5 秒ごと）。メッセージや取り消されたメッセージの元の内容を取りこぼしにくくなりました。
- 外部モニターの添付ファイルをダウンロードできないとき、添付カードに理由を表示します。
- トーク一覧の通話履歴をローカライズした文字で表示します。
- `/adduser` は、相手が Agent の LINE 友だちであることを求めなくなりました。TOKEN が正しければ許可リストに追加します。ログイン時のプライマリ管理者の友だち確認もなくしました。
- Agent の LINE 返信は完全な文にします。情報が足りないときは、途中の文を送らずに必要なことを尋ねます。
- 実行レベルが「フルアクセス」でローカルツールを許可している場合、LINE トークの Agent ジョブで Bash、ウェブ検索、ウェブページの閲覧が使えます。
- ローカル送信ログを追加しました。LINE のホストへの HTTP リクエストを、アプリのデータフォルダーの `logs\line-traffic` に記録します（メッセージ本文は含みません）。保存期間は 14 日または 200 MB です。
- プライマリ管理者のログインボタン名を変更し、外部モニターの実行中は管理者ログインを押せないようにしました。
- いくつかのダイアログのボタン行とチェックボックスの配置を調整しました。
- **実験的機能（まだ使えません）**：QR ログインとアカウントカードに「Chrome 版」ログイン方式を追加しました。ローカルに LINE Chrome 拡張機能 3.7.2 が必要です。未完成のため接続できません。既定の Windows 版を引き続きお使いください。
- 本アプリは引き続き非公式プロジェクトであり、LINE およびその関連会社とは提携・承認・支援関係にありません。

## 한국어

Windows x64 버전입니다. **Assets**에서 `LINE-Agent-Assistant-1.0.302-Setup-x64.exe`를 다운로드하세요. `LINE-Agent-Assistant-1.0.302.zip`은 포터블 버전입니다. SHA-256 값은 `SHA256SUMS.txt`에 있습니다. `latest.yml`과 `.blockmap`은 앱 내 자동 업데이트에 사용됩니다. v1.0.288을 사용 중이면 오른쪽 아래 알림에서 '업데이트'를 선택하면 됩니다.

이전 공개 버전 [v1.0.288](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.288) 이후 변경 사항:

- Agent의 이미지와 파일 전송이 모두 실패하던 문제(업로드 시 HTTP 411)를 수정했습니다.
- 전송에 실패하면 실제 원인(worker 오류 코드, 업로드 단계, 서버 응답)을 남깁니다.
- 로그인: 실패하면 진단 정보를 기록합니다. QR 로그인에 실패하면 계정은 로그아웃 상태로 돌아갑니다. 기존 계정의 QR 로그인을 취소해도 저장된 로그인 정보는 유지되고, 서버에 로그아웃을 보내지 않습니다.
- 외부 모니터는 공식 LINE 데이터베이스가 바뀌면 바로 읽습니다(이전에는 5초마다). 메시지와 취소된 메시지의 원문을 덜 놓칩니다.
- 외부 모니터의 첨부 파일을 내려받을 수 없으면 첨부 카드에 이유를 표시합니다.
- 채팅 목록의 통화 기록을 현지화된 문구로 표시합니다.
- `/adduser`는 상대가 Agent의 LINE 친구일 것을 더 이상 요구하지 않습니다. TOKEN이 맞으면 허용 목록에 추가합니다. 로그인할 때 기본 관리자의 친구 관계 확인도 없앴습니다.
- Agent의 LINE 답장은 완전한 문장이어야 합니다. 정보가 부족하면 문장 조각을 보내지 않고 필요한 내용을 묻습니다.
- 실행 수준이 '전체 액세스'이고 로컬 도구를 허용하면, LINE 채팅의 Agent 작업에서 Bash, 웹 검색, 웹 페이지 열기를 사용할 수 있습니다.
- 로컬 전송 기록을 추가했습니다. LINE 호스트로 보내는 모든 HTTP 요청을 앱 데이터 폴더의 `logs\line-traffic`에 기록합니다(메시지 내용은 제외). 14일 또는 200MB까지 보관합니다.
- 기본 관리자 로그인 버튼 이름을 바꾸고, 외부 모니터 실행 중에는 관리자 로그인을 누를 수 없게 했습니다.
- 여러 대화 상자의 버튼 줄과 체크박스 배치를 다듬었습니다.
- **실험 기능(아직 사용할 수 없음)**: QR 로그인과 계정 카드에 'Chrome 버전' 로그인 방식을 추가했습니다. 로컬에 LINE Chrome 확장 프로그램 3.7.2가 필요합니다. 아직 완성되지 않아 연결할 수 없으니 기본 Windows 버전을 계속 사용하세요.
- 이 앱은 계속 비공식 프로젝트이며 LINE 또는 그 계열사와 제휴 관계가 없고, 이들의 승인이나 후원을 받지 않습니다.
