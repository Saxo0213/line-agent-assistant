## 繁體中文

- **新的 LINE 連線引擎：** Agent 帳號改用 linejs 3.6.9 的 Client 引擎收發訊息，舊引擎已移除。登入時可選擇裝置類型（Windows、Mac、Android 副裝置、iPad）。
- **社群（OpenChat）訊息：** Agent 帳號加入的社群訊息會收進聊天紀錄。
- **訊息畫面：** 時間獨立一行，已讀、已編輯、已收回等狀態在上一行；滑過訊息才顯示「回覆」與「表情」。可手動對訊息按表情、輸入 @ 提及成員、開啟對方的 LINE 個人檔案連結。已收回或已刪除的訊息不能回覆或按表情。編輯過的訊息會保留先前的版本。
- **記事本與相簿：** 一對一聊天也能看記事本與相簿。相簿清單每本相簿顯示三格方形封面，缺少的封面照片會逐張補下載。
- **附件：** 新訊息的附件立即下載；自己傳出的照片與檔案存在本機。附件檔案與紀錄不一致時會自動修正紀錄或重新下載，並留下稽核紀錄。
- **設定 → 資料夾：** 新頁面。選一個聊天室，就能檢視、新增、移除該聊天室給 Agent 使用的專案資料夾，並切換唯讀／讀寫。不會傳送 LINE 訊息，也不會更動磁碟上的檔案。每個聊天室的資料夾數量不再限制 8 個（`/folder` 指令也一樣）。
- **排程：** 新增「照片文字」規則：用本機 OCR 讀出照片中的文字，含關鍵字的照片會轉發。
- **Agent 傳訊：** 可用使用者 MID 傳送一對一訊息，但只限好友或同一群組的成員，陌生人一律拒絕。
- **下載登入：** 官方紀錄不完整時改用擴充功能保存的訊息下載；沒有 E2EE 金鑰的一般媒體也能下載；減少 Chrome 執行的元件。
- **其他：** App 升級後 Agent 會收到一次工具更新通知；Codex 呼叫工具前的說明文字不再混進回覆；錯誤紀錄保留實際的錯誤代碼。

## English

- **New LINE engine:** The Agent account sends and receives through the linejs 3.6.9 Client engine; the old engine is removed. The login can choose the device type (Windows, Mac, Android secondary, iPad).
- **Community (OpenChat) messages:** Messages of communities that the Agent account joined are stored in the chat archive.
- **Message view:** The time is on its own line, with read, edited and unsent states on the line above. **Reply** and the reaction button show on hover. You can react to a message, @-mention members, and open a LINE profile link. Unsent or deleted messages cannot be replied to or reacted to. Earlier versions of edited messages are kept.
- **Notes and albums:** One-to-one chats also show notes and albums. Each album in the list shows three square cover cells, and missing cover photos are downloaded one at a time.
- **Attachments:** Attachments of new messages download at once; photos and files that you send are stored locally. When an attachment file and its record disagree, the app corrects the record or downloads the file again, with an audit record.
- **Settings → Folders:** A new page. Select a chat to view, add and remove the project folders that the Agent can use in that chat, and switch each between read-only and read-write. It sends no LINE message and does not change files on disk. The limit of 8 folders per chat is removed (also for `/folder`).
- **Schedules:** A new photo-text rule reads the text in photos with local OCR and forwards photos that contain the keywords.
- **Agent send:** The Agent can send a one-to-one message by user MID, only to friends or members of a shared group; strangers are refused.
- **Download login:** When the official record is incomplete, the message saved by the extension is used. Plain media without E2EE keys downloads too. Chrome runs fewer components.
- **Other:** After an app upgrade the Agent gets a one-time tool update notice. Codex text before a tool call is no longer part of the reply. Error records keep the real error code.

## 日本語

- **新しい LINE エンジン：** Agent アカウントは linejs 3.6.9 の Client エンジンで送受信します。旧エンジンは削除しました。ログイン時にデバイスの種類（Windows、Mac、Android サブ端末、iPad）を選べます。
- **オープンチャットのメッセージ：** Agent アカウントが参加しているオープンチャットのメッセージを記録に保存します。
- **メッセージ表示：** 時刻は独立した行に、既読・編集済み・送信取消などの状態はその上の行に表示します。「返信」とリアクションボタンはマウスを重ねたときに表示します。リアクション、@ メンション、LINE プロフィールリンクに対応しました。送信取消・削除されたメッセージには返信やリアクションができません。編集されたメッセージは以前の版を保持します。
- **ノートとアルバム：** 1 対 1 のトークでもノートとアルバムを表示します。アルバム一覧は各アルバムに正方形の表紙を 3 枠表示し、足りない表紙写真は 1 枚ずつダウンロードします。
- **添付ファイル：** 新しいメッセージの添付ファイルはすぐにダウンロードし、自分が送った写真とファイルはローカルに保存します。ファイルと記録が一致しない場合は記録を修正するか再ダウンロードし、監査記録を残します。
- **設定 → フォルダー：** 新しいページです。チャットを選ぶと、そのチャットで Agent が使うプロジェクトフォルダーの表示・追加・削除と、読み取り専用／読み書きの切り替えができます。LINE メッセージは送信せず、ディスク上のファイルも変更しません。チャットごとの 8 個の上限を廃止しました（`/folder` も同様）。
- **スケジュール：** 新しい「写真の文字」ルールで、ローカル OCR で読み取った文字にキーワードを含む写真を転送します。
- **Agent の送信：** ユーザー MID で 1 対 1 のメッセージを送れます。友だちか同じグループのメンバーに限り、知らない相手は拒否します。
- **ダウンロード用ログイン：** 公式の記録が不完全な場合は拡張機能が保存したメッセージを使います。E2EE 鍵のない通常のメディアもダウンロードできます。Chrome の実行コンポーネントを減らしました。
- **その他：** アプリ更新後、Agent にツール更新の通知を 1 回送ります。ツール呼び出し前の Codex の説明文は返信に含めません。エラー記録に実際のエラーコードを残します。

## 한국어

- **새 LINE 엔진:** Agent 계정은 linejs 3.6.9 Client 엔진으로 메시지를 주고받습니다. 이전 엔진은 제거했습니다. 로그인할 때 기기 종류(Windows, Mac, Android 보조 기기, iPad)를 선택할 수 있습니다.
- **오픈채팅 메시지:** Agent 계정이 참여한 오픈채팅의 메시지를 기록에 저장합니다.
- **메시지 화면:** 시간은 별도 줄에, 읽음·수정됨·전송 취소 등의 상태는 그 위 줄에 표시합니다. '답장'과 반응 버튼은 마우스를 올릴 때 표시합니다. 반응, @ 멘션, LINE 프로필 링크를 지원합니다. 전송 취소되거나 삭제된 메시지에는 답장하거나 반응할 수 없습니다. 수정된 메시지는 이전 버전을 보관합니다.
- **노트와 앨범:** 1:1 대화에서도 노트와 앨범을 볼 수 있습니다. 앨범 목록은 앨범마다 정사각형 표지 3칸을 표시하고, 없는 표지 사진은 한 장씩 다운로드합니다.
- **첨부 파일:** 새 메시지의 첨부 파일은 바로 다운로드하고, 내가 보낸 사진과 파일은 로컬에 저장합니다. 파일과 기록이 맞지 않으면 기록을 고치거나 다시 다운로드하고 감사 기록을 남깁니다.
- **설정 → 폴더:** 새 페이지입니다. 대화를 선택하면 그 대화에서 Agent가 쓰는 프로젝트 폴더를 보고, 추가하고, 제거하고, 읽기 전용/읽기·쓰기를 바꿀 수 있습니다. LINE 메시지를 보내지 않으며 디스크의 파일도 바꾸지 않습니다. 대화마다 8개였던 제한을 없앴습니다(`/folder`도 동일).
- **예약:** 새 '사진 텍스트' 규칙은 로컬 OCR로 읽은 사진 속 글자에 키워드가 있으면 그 사진을 전달합니다.
- **Agent 전송:** 사용자 MID로 1:1 메시지를 보낼 수 있습니다. 친구나 같은 그룹 멤버에게만 가능하며 모르는 사람은 거부합니다.
- **다운로드용 로그인:** 공식 기록이 불완전하면 확장 프로그램이 저장한 메시지를 사용합니다. E2EE 키가 없는 일반 미디어도 다운로드합니다. Chrome이 실행하는 구성 요소를 줄였습니다.
- **기타:** 앱 업그레이드 후 Agent에 도구 업데이트 알림을 한 번 보냅니다. 도구 호출 전 Codex의 설명 문구는 답장에 넣지 않습니다. 오류 기록에 실제 오류 코드를 남깁니다.
