## 繁體中文

- **摘要規則可自訂：** 摘要改由獨立的 `linejs-summary` Skill 規範，分三步產生：話題骨架、依話題撰寫（【範圍】【概覽】【需要你處理】【話題】【待解決】【檔案與連結】）、逐句核對原話與發言人。規則存在 App 資料夾，主要管理者可請 Agent 修改或恢復預設；各聊天室可用 `/rules add 摘要 <內容>` 加上自己的摘要規則，以聊天室規則為準。排程的總結任務也改用同一份規則。
- **Agent 工具說明重寫：** 所有 MCP 工具與欄位說明改為精確、一致的寫法（觸發條件、欄位、動作）；LINEJS Skill 只保留跨工具規則與呼叫順序，不再有大小上限。
- **指令說明精簡：** 設定 →「指令」表改為「指令／功能／用法」，每列只寫功能與用法；驗證碼說明補上「輸入錯誤 5 次即作廢，需重新 /adduser」。
- **自動回覆隨機回覆：** 回覆訊息可用「；」或「;」分隔多種回覆，每次隨機送出一則。預設回覆改為四種隨機回覆。

## English

- **Custom summary rules:** Summaries follow a separate `linejs-summary` Skill in three passes: a topic outline, the summary by topic (【範圍】【概覽】【需要你處理】【topics】【待解決】【檔案與連結】), and a check of each quote and speaker. The rules are in the app folder. The Primary Admin can ask the Agent to change them or restore the default. Each chat can add its own summary rule with `/rules add 摘要 <text>`; the chat rule wins. Scheduled summary tasks use the same rules.
- **Agent tool descriptions rewritten:** All MCP tool and field descriptions are precise and consistent (trigger, fields, action). The LINEJS Skill keeps only cross-tool rules and the call order, with no size limit.
- **Shorter command help:** Settings → Commands now has the columns Command / Function / Usage, with only the function and usage in each row. The code line now says that 5 wrong entries void the code and `/adduser` must run again.
- **Random auto-replies:** A reply message can hold several replies separated by `；` or `;`. One is sent at random each time. The default reply now has four random replies.

## 日本語

- **要約ルールのカスタマイズ：** 要約は独立した `linejs-summary` Skill に従い、3 段階で作成します：話題の骨組み、話題ごとの作成（【範圍】【概覽】【需要你處理】【話題】【待解決】【檔案與連結】）、引用と発言者の照合。ルールはアプリのフォルダーにあり、メイン管理者は Agent に変更や既定への復元を頼めます。各トークは `/rules add 摘要 <内容>` で独自の要約ルールを追加でき、トークのルールが優先されます。スケジュールの要約タスクも同じルールを使います。
- **Agent ツール説明の書き直し：** すべての MCP ツールと項目の説明を、正確で一貫した書き方（トリガー、項目、動作）にしました。LINEJS Skill はツール間のルールと呼び出し順だけを残し、サイズ上限はなくなりました。
- **コマンド説明の簡略化：** 設定 →「コマンド」表は「コマンド／機能／使い方」になり、各行は機能と使い方だけを示します。認証コードの説明に「5 回間違えると無効、もう一度 /adduser」を追加しました。
- **自動返信のランダム化：** 返信メッセージは「；」または「;」で複数に区切れ、毎回ランダムに 1 件を送ります。既定の返信は 4 種類のランダム返信になりました。

## 한국어

- **요약 규칙 사용자 지정:** 요약은 별도의 `linejs-summary` Skill을 따르며 세 단계로 만듭니다: 주제 골격, 주제별 작성(【範圍】【概覽】【需要你處理】【주제】【待解決】【檔案與連結】), 인용과 발언자 대조. 규칙은 앱 폴더에 있으며 주 관리자는 Agent에게 변경이나 기본값 복원을 요청할 수 있습니다. 각 채팅은 `/rules add 摘要 <내용>`으로 자체 요약 규칙을 추가할 수 있고 채팅 규칙이 우선합니다. 일정의 요약 작업도 같은 규칙을 씁니다.
- **Agent 도구 설명 재작성:** 모든 MCP 도구와 필드 설명을 정확하고 일관된 방식(트리거, 필드, 동작)으로 바꿨습니다. LINEJS Skill은 도구 간 규칙과 호출 순서만 남기며 크기 제한이 없어졌습니다.
- **명령 설명 간소화:** 설정 → '명령' 표는 '명령 / 기능 / 사용법'으로 바뀌었고 각 행은 기능과 사용법만 보여 줍니다. 인증 코드 설명에 '5번 틀리면 무효, /adduser 다시 실행'을 추가했습니다.
- **자동 응답 무작위 선택:** 답장 메시지를 「；」 또는 「;」로 여러 개로 나눌 수 있으며 매번 무작위로 하나를 보냅니다. 기본 답장은 네 가지 무작위 답장이 되었습니다.
