## 繁體中文

- **自動更新：** 「設定 → 關於」新增「自動安裝更新」（預設開啟）。有新版時在背景下載，App 閒置時（沒有 Agent 工作、沒有正在送出的 LINE 訊息）自動安裝並重新開啟；一直沒有閒置時，在關閉 App 時安裝。每個步驟都會記錄在系統紀錄的「自動更新」。安裝在需要系統管理員權限的資料夾（例如 `C:\Program Files`）時，Windows 仍會要求確認。
- **下載用登入不再卡在「啟動中」：** 啟動前會先關閉 App 先前留下的下載用 Chrome。Chrome 啟動後連續 3 次立即結束時停止重試，顯示 `CHROME_EXITED_AT_START` 與 Chrome 的結束代碼；重試期間狀態會顯示次數與原因。
- **錯誤紀錄：** 下載用 Chrome 與附件下載的系統錯誤改為記錄真正的錯誤代碼（新的操作類別 `download_bridge`）。修正一筆社群停權（`LINE_SQUARE_SUSPENDED`）紀錄會讓「系統錯誤」清單無法載入的問題。

## English

- **Automatic update:** **Settings → About** has a new **Install updates automatically** switch (on by default). A new version downloads in the background and installs when the app is idle (no Agent job and no LINE message being sent), then the app reopens. If the app is never idle, the update installs when you quit the app. Each step is recorded in the system records as **Automatic update**. If the app is installed in a folder that needs administrator rights (for example `C:\Program Files`), Windows still asks for confirmation.
- **Download login no longer stays at "Starting":** Before a start, a download Chrome left over by the app is closed. When Chrome ends right after the start 3 times in a row, the app stops retrying and shows `CHROME_EXITED_AT_START` with the Chrome exit code. While it retries, the status shows the count and the reason.
- **Error records:** System errors of the download Chrome and of attachment downloads now record the real error code (new operation `download_bridge`). Fixed a problem where one community suspension record (`LINE_SQUARE_SUSPENDED`) stopped the system errors list from loading.

## 日本語

- **自動更新：** 「設定 → 情報」に「更新を自動でインストール」（既定でオン）を追加しました。新しいバージョンはバックグラウンドでダウンロードされ、アプリがアイドル状態（Agent の処理も送信中の LINE メッセージもない）のときに自動でインストールされ、アプリが再起動します。アイドルにならない場合は、アプリを閉じるときにインストールします。各ステップはシステム記録の「自動更新」に記録されます。管理者権限が必要なフォルダー（例：`C:\Program Files`）にインストールしている場合は、Windows の確認が表示されます。
- **ダウンロード用ログインが「起動中」のまま止まらなくなりました：** 起動前に、アプリが以前に残したダウンロード用 Chrome を閉じます。Chrome が起動直後に 3 回続けて終了した場合は再試行をやめ、`CHROME_EXITED_AT_START` と Chrome の終了コードを表示します。再試行中は回数と理由を表示します。
- **エラー記録：** ダウンロード用 Chrome と添付ファイルのダウンロードのシステムエラーに、実際のエラーコードを記録するようにしました（新しい操作区分 `download_bridge`）。オープンチャットの停止（`LINE_SQUARE_SUSPENDED`）の記録が 1 件あると「システムエラー」一覧を読み込めない問題を修正しました。

## 한국어

- **자동 업데이트:** '설정 → 정보'에 '업데이트 자동 설치'(기본 켜짐)를 추가했습니다. 새 버전은 백그라운드에서 다운로드되고, 앱이 유휴 상태(Agent 작업과 전송 중인 LINE 메시지가 없음)일 때 자동으로 설치된 뒤 앱이 다시 열립니다. 유휴 상태가 오지 않으면 앱을 닫을 때 설치합니다. 각 단계는 시스템 기록의 '자동 업데이트'에 남습니다. 관리자 권한이 필요한 폴더(예: `C:\Program Files`)에 설치한 경우 Windows 확인 창은 계속 표시됩니다.
- **다운로드용 로그인이 '시작 중'에 멈추지 않음:** 시작하기 전에 앱이 이전에 남긴 다운로드용 Chrome을 닫습니다. Chrome이 시작 직후 3번 연속 종료되면 재시도를 멈추고 `CHROME_EXITED_AT_START`와 Chrome 종료 코드를 표시합니다. 재시도 중에는 횟수와 원인을 표시합니다.
- **오류 기록:** 다운로드용 Chrome과 첨부 파일 다운로드의 시스템 오류에 실제 오류 코드를 기록합니다(새 작업 구분 `download_bridge`). 오픈채팅 정지(`LINE_SQUARE_SUSPENDED`) 기록 1건 때문에 '시스템 오류' 목록을 불러오지 못하던 문제를 수정했습니다.
