## 繁體中文

- **分類資料夾：** 每個聊天室可設定一個「預設資料夾」及最多 10 個「分類資料夾」，每個分類資料夾附一段說明；附件下載後由 Agent 依說明判斷要複製到哪個分類資料夾，判斷不出來就放預設資料夾。支援網路共用資料夾（NAS、`\\伺服器\共用`），複製後會讀回比對 SHA-256。
- **聊天室設定：** 聊天室標題列的齒輪改為「聊天室設定」視窗，固定大小、內容捲動，分為「下載資料夾」、「Agent 權限資料夾」、「權限設定」三個分頁；開啟、更換、移除按鈕與資料夾路徑同一行靠右。標題列移除「Agent 觸發」文字，四個按鈕大小與間距一致。設定頁的資料夾也分成「權限資料夾」與「下載資料夾」兩區。
- **已儲存檔案：** 依發言人分標籤，欄位為訊息日期、類型、大小、檔名、開啟；開啟按鈕只顯示「開啟」。沒有檔名的附件不再顯示「undefined」。
- **Agent 管理資料夾：** Agent 可透過 MCP 工具列出、新增、修改說明、設定預設與移除聊天室的下載資料夾（主要管理者）。白名單使用者可在自己的聊天室新增、修改說明與移除分類資料夾，但只能建在預設資料夾底下的子資料夾，不能變更預設資料夾。
- **群組呼叫 Agent：** 在群組中只傳「@Agent」也會呼叫 Agent，Agent 會參考最近的聊天內容回應。
- **LINE 指令：** 在與 Agent 的 1:1 輸入 `/權限`（或 `/permissions`），可依編號選擇群組或個人、群組成員，再切換各項權限（預設為否）；本機讀寫設定不能從 LINE 修改，確認時回覆 y／n。群組中的 `/adduser` 可一次標記最多 10 位使用者。
- **更新：** 「立即更新」會立刻安裝已下載的更新；若 App 不是閒置狀態，會顯示原因。

## English

- **Classification folders:** Each chat can have one **default folder** and up to 10 **classification folders**, each with a description. After an attachment downloads, the Agent uses the descriptions to choose the classification folder for the copy; when it cannot choose, the copy goes to the default folder. Network shares (NAS, `\\server\share`) are supported, and each copy is read back and checked with SHA-256.
- **Chat settings:** The gear in the chat header now opens **Chat settings**, a fixed-size window that scrolls, with the tabs **Download folders**, **Agent access folders** and **Permissions**. Open, change and remove sit on the folder path row, on the right. The header no longer shows "Agent trigger", and its four buttons share one size and gap. In Settings, folders are also split into permission folders and download folders.
- **Saved files:** Tabs by sender, with the columns message date, type, size, file name and open. The open button shows only **Open**. Attachments without a name no longer show "undefined".
- **Agent folder management:** The Agent can list, add, describe, set as default and remove a chat's download folders with MCP tools (Primary Admin). A whitelisted user can add, describe and remove classification folders of their own chat, only as subfolders of the default folder, and cannot change the default folder.
- **Calling the Agent in a group:** A message with only "@Agent" in a group now calls the Agent, which answers from the recent chat messages.
- **LINE commands:** In the 1:1 chat with the Agent, `/權限` (or `/permissions`) lists groups and persons, then group members, by number, and then the permissions to switch (default no). Local read/write settings cannot be changed from LINE, and confirmations take y/n. In a group, `/adduser` takes up to 10 user mentions at once.
- **Updates:** **Update now** installs a downloaded update at once; when the app is not idle, it shows why.

## 日本語

- **分類フォルダー：** トークごとに「既定のフォルダー」1 つと、説明付きの「分類フォルダー」を最大 10 個設定できます。添付ファイルのダウンロード後、Agent が説明をもとにコピー先の分類フォルダーを選び、選べない場合は既定のフォルダーにコピーします。ネットワーク共有（NAS、`\\サーバー\共有`）に対応し、コピー後に読み戻して SHA-256 を照合します。
- **トーク設定：** トークのヘッダーの歯車で「チャット設定」を開くようにしました。固定サイズでスクロールでき、「ダウンロードフォルダー」「Agent アクセスフォルダー」「権限設定」の 3 つのタブがあります。開く・変更・削除のボタンはフォルダーのパスと同じ行の右側に並びます。ヘッダーから「Agent トリガー」の表示をなくし、4 つのボタンのサイズと間隔をそろえました。設定画面のフォルダーも権限フォルダーとダウンロードフォルダーに分けました。
- **保存済みファイル：** 発言者ごとのタブと、メッセージ日付・種類・サイズ・ファイル名・開くの列を表示します。開くボタンは「開く」のみ表示します。名前のない添付ファイルに「undefined」と表示されなくなりました。
- **Agent によるフォルダー管理：** Agent は MCP ツールでトークのダウンロードフォルダーの一覧・追加・説明変更・既定設定・削除ができます（メイン管理者）。ホワイトリストのユーザーは自分のトークの分類フォルダーを追加・説明変更・削除できますが、既定のフォルダーの下のサブフォルダーに限られ、既定のフォルダーは変更できません。
- **グループでの Agent 呼び出し：** グループで「@Agent」だけを送っても Agent が呼び出され、最近のトーク内容をもとに返信します。
- **LINE コマンド：** Agent との 1:1 で `/權限`（または `/permissions`）を入力すると、グループ・個人、グループのメンバーを番号で選び、各権限（既定は「いいえ」）を切り替えられます。ローカルの読み書き設定は LINE から変更できず、確認は y／n で答えます。グループの `/adduser` は一度に最大 10 人のユーザーをメンションできます。
- **更新：** 「今すぐ更新」でダウンロード済みの更新をすぐにインストールします。アプリがアイドルでない場合は理由を表示します。

## 한국어

- **분류 폴더:** 채팅마다 '기본 폴더' 1개와 설명이 있는 '분류 폴더'를 최대 10개까지 설정할 수 있습니다. 첨부 파일 다운로드 후 Agent가 설명을 보고 복사할 분류 폴더를 고르며, 고를 수 없으면 기본 폴더에 복사합니다. 네트워크 공유(NAS, `\\서버\공유`)를 지원하며, 복사 후 다시 읽어 SHA-256을 확인합니다.
- **채팅 설정:** 채팅 헤더의 톱니바퀴로 '채팅 설정'을 엽니다. 크기가 고정되고 내용은 스크롤되며, '다운로드 폴더', 'Agent 접근 폴더', '권한 설정' 탭이 있습니다. 열기, 변경, 제거 버튼은 폴더 경로와 같은 줄 오른쪽에 있습니다. 헤더에서 'Agent 트리거' 표시를 없애고 네 버튼의 크기와 간격을 맞췄습니다. 설정 화면의 폴더도 권한 폴더와 다운로드 폴더로 나눴습니다.
- **저장된 파일:** 발신자별 탭과 메시지 날짜, 유형, 크기, 파일 이름, 열기 열을 표시합니다. 열기 버튼에는 '열기'만 표시됩니다. 이름이 없는 첨부 파일에 'undefined'가 더 이상 표시되지 않습니다.
- **Agent 폴더 관리:** Agent는 MCP 도구로 채팅의 다운로드 폴더를 조회, 추가, 설명 변경, 기본 지정, 제거할 수 있습니다(주 관리자). 화이트리스트 사용자는 자신의 채팅에서 분류 폴더를 추가, 설명 변경, 제거할 수 있지만 기본 폴더 아래의 하위 폴더만 가능하며 기본 폴더는 바꿀 수 없습니다.
- **그룹에서 Agent 호출:** 그룹에서 '@Agent'만 보내도 Agent가 호출되며, 최근 대화 내용을 바탕으로 답합니다.
- **LINE 명령:** Agent와의 1:1에서 `/權限`(또는 `/permissions`)을 입력하면 그룹·개인, 그룹 멤버를 번호로 고른 뒤 각 권한(기본값 아니요)을 전환할 수 있습니다. 로컬 읽기/쓰기 설정은 LINE에서 바꿀 수 없으며, 확인은 y/n으로 답합니다. 그룹의 `/adduser`는 한 번에 최대 10명의 사용자를 멘션할 수 있습니다.
- **업데이트:** '지금 업데이트'는 다운로드된 업데이트를 바로 설치합니다. 앱이 유휴 상태가 아니면 그 이유를 표시합니다.
