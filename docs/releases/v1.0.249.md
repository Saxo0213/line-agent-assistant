# v1.0.249 — changes since v1.0.244

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE.Agent.Assistant-1.0.249-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.249.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。

相較於上一個公開版本 v1.0.244：

- 操作失敗資訊會更清楚指出發生問題的操作，方便理解錯誤原因。
- 相簿清單與照片目錄會保留掃描結果，讓後續瀏覽可以重用；也減少重複照片處理。
- 記錄主要管理員已確認為 LINE 好友的狀態，管理員資料變更後會重新確認。
- 相簿照片可顯示預覽與本機儲存狀態。已儲存的照片會使用易辨識的資料夾與檔名，並以獨立副本保存。

## English

Windows x64 release. Download `LINE.Agent.Assistant-1.0.249-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.249.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`.

Changes since the previous public release, v1.0.244:

- Operation failures now provide clearer information about which action failed.
- Album and photo scans retain their catalog progress for later browsing, with less repeated work on duplicate photos.
- The app remembers when the primary administrator has been confirmed as a LINE friend and checks again if the administrator changes.
- Album photos show previews and whether they are saved locally. Saved photos use readable folder and file names and are stored as independent copies.

## 日本語

Windows x64 版です。**Assets** から `LINE.Agent.Assistant-1.0.249-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.249.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。

前回の公開版 v1.0.244 からの変更点：

- どの操作で失敗したかが分かりやすくなりました。
- アルバムと写真のスキャン結果を保存し、次回の閲覧で再利用できるようにしました。重複写真の処理も減らしました。
- 主要管理者が LINE の友だちであることを確認した状態を記録し、管理者が変更された場合は再確認します。
- アルバム写真のプレビューとローカル保存状態を表示します。保存した写真は、分かりやすいフォルダー名とファイル名を使い、独立したコピーとして保存します。
