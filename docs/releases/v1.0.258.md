# v1.0.258 — changes since v1.0.254

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE.Agent.Assistant-1.0.258-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.258.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。

相較於上一個公開版本 v1.0.254：

- **重要：** 不再自動以 MID 加 LINE 好友。主要管理員若還不是 Agent 的好友，系統錯誤會提示請管理員主動加 Agent 為好友；`/新增使用者` 的對象不是好友時，會回覆請對方先加 Agent 為好友。原因是自動加好友後，LINE 曾登出 Agent 帳號並限制登入。
- 主要管理員好友檢查改在 Agent 登入完成後才執行，檢查失敗時會重試，每一步的失敗原因都會寫入系統錯誤。
- 內建資料庫的連接埠被其他程式佔用時，會自動改用其他可用的連接埠；新安裝改用 45432–45531，避開 Windows 動態連接埠範圍。
- 系統錯誤表重新排版：日期與時間分兩行，「紀錄」欄顯示標題、說明、代碼與紀錄編號，「操作」欄顯示操作、階段、原因與處理方式，內容一律靠上對齊。
- 系統紀錄與系統錯誤會記住上次選取的分頁。

## English

Windows x64 release. Download `LINE.Agent.Assistant-1.0.258-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.258.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`.

Changes since the previous public release, v1.0.254:

- **Important:** The app no longer adds LINE friends by MID automatically. If the primary administrator is not yet a friend of the Agent, a system error asks the administrator to add the Agent. If the person being added with `/adduser` is not a friend, the reply asks them to add the Agent first. After an automatic friend add, LINE once logged the Agent account out and restricted its login.
- The primary administrator friend check now runs only after the Agent has logged in. Failed checks are retried, and every failing step is written to System Errors.
- When another program holds the embedded database port, the app moves to another free port. New installs use 45432–45531, outside the Windows dynamic port range.
- System Errors has a new layout. Date and time are on two lines. The Record column shows the title, explanation, code, and record ID. The Action column shows the operation, stage, reason, and how to recover. All cells are top-aligned.
- System Records and System Errors remember the last selected tab.

## 日本語

Windows x64 版です。**Assets** から `LINE.Agent.Assistant-1.0.258-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.258.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。

前回の公開版 v1.0.254 からの変更点：

- **重要：** MID による LINE 友だちの自動追加を廃止しました。主要管理者がまだ Agent の友だちでない場合は、システムエラーで管理者に Agent の友だち追加を依頼します。`/adduser` の対象が友だちでない場合は、先に Agent を友だち追加するよう返信します。自動追加の後、LINE が Agent アカウントをログアウトさせ、ログインを制限したことがあるためです。
- 主要管理者の友だち確認は、Agent のログイン完了後に実行するようにしました。失敗した確認は再試行し、各ステップの失敗理由をシステムエラーに記録します。
- 内蔵データベースのポートが他のプログラムに使われている場合、空いている別のポートに自動で切り替えます。新規インストールでは Windows の動的ポート範囲を避けて 45432–45531 を使います。
- システムエラー表のレイアウトを変更しました。日付と時刻を 2 行に分け、「記録」列にタイトル・説明・コード・記録番号を、「操作」列に操作・段階・原因・対処方法を表示し、すべて上揃えにしました。
- システム記録とシステムエラーは、前回選択したタブを記憶します。

## 한국어

Windows x64 버전입니다. **Assets**에서 `LINE.Agent.Assistant-1.0.258-Setup-x64.exe`를 다운로드하세요. `LINE-Agent-Assistant-1.0.258.zip`은 포터블 버전입니다. SHA-256 값은 `SHA256SUMS.txt`에 있습니다.

이전 공개 버전 v1.0.254 이후 변경 사항:

- **중요:** MID로 LINE 친구를 자동 추가하지 않습니다. 기본 관리자가 아직 Agent의 친구가 아니면, 시스템 오류에서 관리자에게 Agent를 친구로 추가하도록 안내합니다. `/adduser` 대상이 친구가 아니면, 먼저 Agent를 친구로 추가하라고 답장합니다. 자동 친구 추가 후 LINE이 Agent 계정을 로그아웃시키고 로그인을 제한한 적이 있기 때문입니다.
- 기본 관리자 친구 확인은 Agent 로그인이 끝난 뒤에만 실행합니다. 실패한 확인은 다시 시도하며, 각 단계의 실패 원인을 시스템 오류에 기록합니다.
- 내장 데이터베이스 포트를 다른 프로그램이 사용 중이면 비어 있는 다른 포트로 자동 전환합니다. 새로 설치할 때는 Windows 동적 포트 범위를 피해 45432–45531을 사용합니다.
- 시스템 오류 표의 레이아웃을 바꿨습니다. 날짜와 시간을 두 줄로 나누고, 「기록」 열에 제목·설명·코드·기록 번호를, 「작업」 열에 작업·단계·원인·처리 방법을 표시하며, 모든 내용을 위쪽 정렬합니다.
- 시스템 기록과 시스템 오류는 마지막으로 선택한 탭을 기억합니다.
