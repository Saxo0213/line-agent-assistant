# v1.0.279 — changes since v1.0.270

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE.Agent.Assistant-1.0.279-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.279.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。

相較於上一個公開版本 [v1.0.270](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.270)：

- 新增「排程」頁：可依單次、每日、每週、固定間隔或 cron 觸發 Agent，執行聊天室摘要、關鍵字追蹤、自訂指令或定時系統訊息。結果預設傳給主要管理者，每次執行使用獨立的工作階段。
- 排程可設定隨機延後 0–5 分鐘，避免每次都在固定時間執行；Agent 查詢排程時預設只列出啟用中的排程。
- 新增群組自由模式：主要管理者在已啟用 Agent 的群組輸入 `/free` 或 `/free N`（1–120 分鐘，預設 5 分鐘），期間內 Agent 不需被標註即可依對話內容回覆；輸入 `/free off` 關閉。
- 更換 Agent 帳號後，延續舊帳號的對話紀錄與 Agent 記憶，排程目標也會對應到目前的帳號。
- 聊天室中分享的聯絡人卡片會提供給 Agent，用於辨識對象。
- Agent 的訊息查詢工具改為分頁回傳結果，不再固定只取 200 則。
- 「設定 → 關於」新增自動檢查更新開關：每 6 小時檢查本 repository 是否有新安裝檔，有新版時側欄「設定」會顯示驚嘆號。
- 訊息接收會略過 worker 重送的重複批次，並在系統紀錄中記錄過慢的接收階段；worker 指令改用嚴格格式，worker 發生錯誤時會立即結束等待中的請求。
- Claude 工作階段在 400K tokens 時自動壓縮；Codex 使用 CLI 預設值。
- 修正新 worker 啟動時控制確認逾時的問題，並記錄啟動時的登入失敗。
- 本程式仍為非官方專案，與 LINE 無隸屬、背書或贊助關係。

## English

Windows x64 release. Download `LINE.Agent.Assistant-1.0.279-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.279.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`.

Changes since the previous public release, [v1.0.270](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.270):

- New Schedules page: trigger the Agent once, daily, weekly, at a fixed interval, or by cron expression to summarize chats, track keywords, run a custom prompt, or send a timed system message. Results go to the Primary Admin by default, and each run uses its own isolated session.
- Schedules can start a random 0–5 minutes late so they do not always run at the same moment. When the Agent lists schedules, it shows only enabled ones by default.
- New group free mode: in a group where the Agent is enabled, the Primary Admin sends `/free` or `/free N` (1–120 minutes, default 5). During that time the Agent replies from the conversation without being mentioned. `/free off` ends it.
- After the Agent account is replaced, conversation history and Agent memory carry over from the former account, and schedule targets resolve to the current account.
- Contact cards shared in a chat are passed to the Agent so it can identify people.
- The Agent's message query tool now returns paged results instead of a fixed cap of 200 messages.
- Settings → About has an automatic update check: every 6 hours it checks this repository for a newer installer, and the Settings item in the sidebar shows an exclamation mark when one is available.
- Message ingest skips batches that the worker re-sends and records slow ingest stages in the system records. Worker commands use a strict format, and pending requests end immediately when the worker reports an error.
- Claude sessions auto-compact at 400K tokens; Codex uses its CLI default.
- Fixed control-acknowledgement timeouts when a new worker starts, and startup login failures are now recorded.
- This remains an unofficial project and is not affiliated with, endorsed by, or sponsored by LINE or its affiliates.

## 日本語

Windows x64 版です。**Assets** から `LINE.Agent.Assistant-1.0.279-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.279.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。

前回の公開版 [v1.0.270](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.270) からの変更点：

- 「スケジュール」ページを追加しました。1 回のみ、毎日、毎週、一定間隔、または cron で Agent を起動し、トークの要約、キーワード追跡、カスタム指示、定時のシステムメッセージを実行できます。結果は既定でプライマリ管理者に送られ、実行ごとに独立したセッションを使います。
- スケジュールは 0～5 分のランダムな遅延を設定でき、毎回同じ時刻に実行されないようにできます。Agent がスケジュールを一覧表示する際は、既定で有効なものだけを表示します。
- グループのフリーモードを追加しました。Agent が有効なグループでプライマリ管理者が `/free` または `/free N`（1～120 分、既定 5 分）を送ると、その間 Agent はメンションなしで会話に応じて返信します。`/free off` で終了します。
- Agent アカウントを置き換えた後も、以前のアカウントの会話履歴と Agent の記憶を引き継ぎ、スケジュールの対象も現在のアカウントに対応します。
- トークで共有された連絡先カードを Agent に渡し、相手の識別に使えるようにしました。
- Agent のメッセージ検索ツールは、200 件の固定上限ではなくページ単位で結果を返します。
- 「設定 → 情報」に自動更新チェックを追加しました。6 時間ごとにこのリポジトリの新しいインストーラーを確認し、新版がある場合はサイドバーの「設定」に感嘆符を表示します。
- メッセージ受信時にワーカーが再送した重複バッチを無視し、遅い受信段階をシステム記録に残します。ワーカーへのコマンドは厳密な形式を使い、ワーカーがエラーを報告すると待機中のリクエストを直ちに終了します。
- Claude のセッションは 400K トークンで自動圧縮し、Codex は CLI の既定値を使います。
- 新しいワーカー起動時の制御確認のタイムアウトを修正し、起動時のログイン失敗を記録するようにしました。
- 本アプリは引き続き非公式プロジェクトであり、LINE およびその関連会社とは提携・承認・支援関係にありません。

## 한국어

Windows x64 버전입니다. **Assets**에서 `LINE.Agent.Assistant-1.0.279-Setup-x64.exe`를 다운로드하세요. `LINE-Agent-Assistant-1.0.279.zip`은 포터블 버전입니다. SHA-256 값은 `SHA256SUMS.txt`에 있습니다.

이전 공개 버전 [v1.0.270](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.270) 이후 변경 사항:

- '예약' 페이지를 추가했습니다. 한 번, 매일, 매주, 일정 간격 또는 cron으로 Agent를 실행해 채팅 요약, 키워드 추적, 사용자 지정 지시, 정시 시스템 메시지를 처리할 수 있습니다. 결과는 기본적으로 기본 관리자에게 전달되며, 실행마다 독립된 세션을 사용합니다.
- 예약은 0~5분의 무작위 지연을 설정해 매번 같은 시각에 실행되지 않게 할 수 있습니다. Agent가 예약 목록을 조회할 때는 기본적으로 활성화된 예약만 표시합니다.
- 그룹 자유 모드를 추가했습니다. Agent가 활성화된 그룹에서 기본 관리자가 `/free` 또는 `/free N`(1~120분, 기본 5분)을 보내면 그동안 Agent가 멘션 없이 대화 내용에 따라 답장합니다. `/free off`로 종료합니다.
- Agent 계정을 교체한 뒤에도 이전 계정의 대화 기록과 Agent 기억을 이어받고, 예약 대상도 현재 계정에 대응합니다.
- 채팅에서 공유된 연락처 카드를 Agent에 전달해 상대를 식별할 수 있게 했습니다.
- Agent의 메시지 조회 도구는 200건 고정 상한 대신 페이지 단위로 결과를 반환합니다.
- '설정 → 정보'에 자동 업데이트 확인을 추가했습니다. 6시간마다 이 저장소에 새 설치 파일이 있는지 확인하고, 새 버전이 있으면 사이드바의 '설정'에 느낌표를 표시합니다.
- 메시지 수신 시 worker가 다시 보낸 중복 배치를 건너뛰고, 느린 수신 단계를 시스템 기록에 남깁니다. worker 명령은 엄격한 형식을 사용하며, worker가 오류를 보고하면 대기 중인 요청을 즉시 종료합니다.
- Claude 세션은 400K 토큰에서 자동 압축하며, Codex는 CLI 기본값을 사용합니다.
- 새 worker 시작 시 제어 확인 시간 초과 문제를 수정하고, 시작 시 로그인 실패를 기록하도록 했습니다.
- 이 앱은 계속 비공식 프로젝트이며 LINE 또는 그 계열사와 제휴 관계가 없고, 이들의 승인이나 후원을 받지 않습니다.
