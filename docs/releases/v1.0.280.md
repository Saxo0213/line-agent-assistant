# v1.0.280 — changes since v1.0.279

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE-Agent-Assistant-1.0.280-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.280.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。`latest.yml` 與 `.blockmap` 供 App 內自動更新使用。

相較於上一個公開版本 [v1.0.279](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.279)：

- 檢查到新版本時，視窗右下角會顯示「更新」與「忽略」提示。選擇「更新」會在背景下載安裝檔、以 SHA-512 驗證，正常關閉服務後安裝並重新啟動 App。
- 「忽略」只略過該版本；有更新的版本時會再次提示。「設定 → 關於」新增「立即更新」。
- 從原始碼執行、發布版本未附 `latest.yml`，或下載失敗時，會改為開啟下載頁。
- 自動更新從本版開始提供；v1.0.279 以前的版本仍需手動下載安裝本版。安裝檔目前未經程式碼簽章。
- 本程式仍為非官方專案，與 LINE 無隸屬、背書或贊助關係。

## English

Windows x64 release. Download `LINE-Agent-Assistant-1.0.280-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.280.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`. `latest.yml` and the `.blockmap` are used by the in-app updater.

Changes since the previous public release, [v1.0.279](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.279):

- When a newer version is found, a prompt with Update and Ignore appears at the bottom-right of the window. Update downloads the installer in the background, verifies its SHA-512, shuts the services down normally, installs, and restarts the app.
- Ignore skips only that version; a later version prompts again. Settings → About adds an Update now button.
- When running from source, when a release has no `latest.yml`, or when the download fails, the app opens the download page instead.
- Automatic updates start with this version; v1.0.279 and earlier must download and install this version manually. The installer is not code-signed.
- This remains an unofficial project and is not affiliated with, endorsed by, or sponsored by LINE or its affiliates.

## 日本語

Windows x64 版です。**Assets** から `LINE-Agent-Assistant-1.0.280-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.280.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。`latest.yml` と `.blockmap` はアプリ内の自動更新で使用します。

前回の公開版 [v1.0.279](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.279) からの変更点：

- 新しいバージョンが見つかると、ウィンドウ右下に「更新」と「無視」の通知を表示します。「更新」を選ぶと、インストーラーをバックグラウンドでダウンロードして SHA-512 で検証し、サービスを通常どおり終了してからインストールし、アプリを再起動します。
- 「無視」はそのバージョンだけをスキップし、さらに新しいバージョンでは再度通知します。「設定 → 情報」に「今すぐ更新」を追加しました。
- ソースから実行している場合、リリースに `latest.yml` がない場合、またはダウンロードに失敗した場合は、ダウンロードページを開きます。
- 自動更新は本バージョンから利用できます。v1.0.279 以前は本バージョンを手動でダウンロードしてインストールしてください。インストーラーにはコード署名がありません。
- 本アプリは引き続き非公式プロジェクトであり、LINE およびその関連会社とは提携・承認・支援関係にありません。

## 한국어

Windows x64 버전입니다. **Assets**에서 `LINE-Agent-Assistant-1.0.280-Setup-x64.exe`를 다운로드하세요. `LINE-Agent-Assistant-1.0.280.zip`은 포터블 버전입니다. SHA-256 값은 `SHA256SUMS.txt`에 있습니다. `latest.yml`과 `.blockmap`은 앱 내 자동 업데이트에 사용됩니다.

이전 공개 버전 [v1.0.279](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.279) 이후 변경 사항:

- 새 버전이 발견되면 창 오른쪽 아래에 '업데이트'와 '무시' 알림이 표시됩니다. '업데이트'를 선택하면 설치 파일을 백그라운드에서 다운로드해 SHA-512로 확인하고, 서비스를 정상 종료한 뒤 설치하고 앱을 다시 시작합니다.
- '무시'는 해당 버전만 건너뛰며, 더 새로운 버전이 나오면 다시 알립니다. '설정 → 정보'에 '지금 업데이트'를 추가했습니다.
- 소스에서 실행하는 경우, 릴리스에 `latest.yml`이 없는 경우, 또는 다운로드에 실패한 경우에는 다운로드 페이지를 엽니다.
- 자동 업데이트는 이 버전부터 제공됩니다. v1.0.279 이하 버전은 이 버전을 직접 다운로드해 설치해야 합니다. 설치 파일에는 코드 서명이 없습니다.
- 이 앱은 계속 비공식 프로젝트이며 LINE 또는 그 계열사와 제휴 관계가 없고, 이들의 승인이나 후원을 받지 않습니다.
