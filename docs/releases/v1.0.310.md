# v1.0.310 — changes since v1.0.305

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE-Agent-Assistant-1.0.310-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.310.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。`latest.yml` 與 `.blockmap` 供 App 內自動更新使用；已安裝 v1.0.305 的使用者可直接在右下角提示選擇「更新」。

相較於上一個公開版本 [v1.0.305](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.305)：

- **排程分成兩種**：程式排程（系統訊息、新訊息）由系統直接完成；Agent 排程（自訂、總結、關鍵字摘要）每次都會啟動 Agent。表單先選種類，列表也會標示。
- **新訊息排程**：系統自己讀取時間範圍內的新訊息並傳送清單，不需要 LLM。不選聊天室時讀取所有可讀的聊天室。
- **可組合的條件**：可設定訊息過濾與多條規則，每個聊天室由第一條符合的規則決定「列出」、「略過」或「交給 LLM 總結」。條件可用全部符合／任一符合組合，最多兩層。例如訊息超過 20 則的聊天室才交給 LLM。
- **試算**：新訊息排程的表單可以先試算結果，試算只讀取訊息，不會傳送，也不會啟動 LLM。
- 新訊息排程傳出的清單不會在下一輪再次列出；同一群組由兩個帳號收到時只列一次；單次清單最多 49,000 字元，超過時會註明未列出的聊天室與訊息數。
- 已知限制：清單已傳送但 Agent 工作建立失敗時，該次記為失敗，下一輪會重新列出相同訊息。
- **MCP 查詢**：`query_target_messages_by_time` 只要提供開始時間，就能一次查詢所有聊天室；新增 `list_active_chats`，列出時間範圍內有訊息的聊天室與計數；新增 `excludeChatIds`、`direction`、`kinds`、`excludeKinds` 過濾條件。
- **修正 MCP 日期查詢差 8 小時**：只有日期的時間範圍現在以台灣時間的一天計算。
- **修正連線狀態誤判**：同步長輪詢逾時回傳的 410 不再被判定為連線異常。
- 本程式仍為非官方專案，與 LINE 無隸屬、背書或贊助關係。

## English

Windows x64 release. Download `LINE-Agent-Assistant-1.0.310-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.310.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`. `latest.yml` and the `.blockmap` are used by the in-app updater; if v1.0.305 is installed, choose **Update** in the bottom-right prompt.

Changes since the previous public release, [v1.0.305](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.305):

- **Two kinds of schedule:** program schedules (system message, new messages) are done by the app itself; Agent schedules (custom, summary, keyword digest) start an Agent on every run. The form asks for the kind first, and the list shows it.
- **New messages schedule:** the app reads the new messages of the time range and sends a list with no LLM. With no chats selected, it reads every readable chat.
- **Composable conditions:** set a message filter and several rules. For each chat, the first matching rule selects list, skip, or hand to the LLM to summarize. Conditions combine with all/any, up to two levels. For example, only chats with more than 20 messages go to the LLM.
- **Preview:** the new messages form can preview the result. A preview only reads messages; it sends nothing and starts no LLM.
- A list sent by a new messages schedule is not listed again in the next run. A group received by two accounts is listed once. One list is at most 49,000 characters, and a longer list states how many chats and messages it left out.
- Known limit: if a list is sent but the Agent job cannot be created, the run is recorded as failed and the next run lists the same messages again.
- **MCP queries:** `query_target_messages_by_time` can read all chats in one query when given a start time. New tool `list_active_chats` lists the chats with messages in a time range, with counts. New filters: `excludeChatIds`, `direction`, `kinds`, and `excludeKinds`.
- **Fixed the 8-hour offset in MCP date queries:** date-only time bounds now mean a day in Taiwan time.
- **Fixed a false connection error:** a 410 from an idle sync long poll no longer counts as a connection failure.
- This remains an unofficial project and is not affiliated with, endorsed by, or sponsored by LINE or its affiliates.

## 日本語

Windows x64 版です。**Assets** から `LINE-Agent-Assistant-1.0.310-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.310.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。`latest.yml` と `.blockmap` はアプリ内の自動更新で使用します。v1.0.305 をお使いの場合は、右下の通知で「更新」を選択できます。

前回の公開版 [v1.0.305](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.305) からの変更点：

- **スケジュールが 2 種類に**：プログラム実行のスケジュール（システムメッセージ、新着メッセージ）はアプリ自身が処理します。Agent 実行のスケジュール（カスタム、要約、キーワード抽出）は実行のたびに Agent を起動します。フォームでは最初に種類を選び、一覧にも表示されます。
- **新着メッセージスケジュール**：アプリが時間範囲内の新着メッセージを読み取り、LLM なしで一覧を送信します。トークを選択しない場合は、読み取り可能なすべてのトークが対象です。
- **組み合わせ可能な条件**：メッセージフィルターと複数のルールを設定できます。トークごとに、最初に一致したルールが「一覧にする」「除外する」「LLM に要約させる」を決めます。条件は「すべて一致／いずれか一致」で最大 2 階層まで組み合わせられます。たとえば、メッセージが 20 件を超えるトークだけを LLM に要約させられます。
- **プレビュー**：新着メッセージのフォームで結果をプレビューできます。プレビューは読み取りのみで、送信も LLM の起動も行いません。
- 新着メッセージスケジュールが送信した一覧は、次回の一覧に含まれません。2 つのアカウントが受信した同じグループは 1 回だけ表示します。1 回の一覧は最大 49,000 文字で、超えた場合は表示しなかったトーク数とメッセージ数を記載します。
- 既知の制限：一覧の送信後に Agent ジョブを作成できなかった場合、その回は失敗として記録され、次回に同じメッセージを再度表示します。
- **MCP クエリ**：`query_target_messages_by_time` は開始時刻を指定すれば 1 回ですべてのトークを照会できます。新しいツール `list_active_chats` は、時間範囲内にメッセージがあるトークと件数を返します。新しいフィルターは `excludeChatIds`、`direction`、`kinds`、`excludeKinds` です。
- **MCP の日付クエリの 8 時間のずれを修正**：日付のみの範囲は台湾時間の 1 日として扱います。
- **接続エラーの誤判定を修正**：同期のロングポーリングが返す 410 を接続エラーとして扱わなくなりました。
- 本アプリは引き続き非公式プロジェクトであり、LINE およびその関連会社とは提携・承認・支援関係にありません。

## 한국어

Windows x64 버전입니다. **Assets**에서 `LINE-Agent-Assistant-1.0.310-Setup-x64.exe`를 다운로드하세요. `LINE-Agent-Assistant-1.0.310.zip`은 포터블 버전입니다. SHA-256 값은 `SHA256SUMS.txt`에 있습니다. `latest.yml`과 `.blockmap`은 앱 내 자동 업데이트에 사용됩니다. v1.0.305를 사용 중이면 오른쪽 아래 알림에서 '업데이트'를 선택하면 됩니다.

이전 공개 버전 [v1.0.305](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.305) 이후 변경 사항:

- **두 종류의 일정**: 프로그램 일정(시스템 메시지, 새 메시지)은 앱이 직접 처리합니다. Agent 일정(사용자 지정, 요약, 키워드 모음)은 실행할 때마다 Agent를 시작합니다. 양식에서 먼저 종류를 선택하며 목록에도 표시됩니다.
- **새 메시지 일정**: 앱이 시간 범위의 새 메시지를 읽고 LLM 없이 목록을 보냅니다. 채팅을 선택하지 않으면 읽을 수 있는 모든 채팅을 읽습니다.
- **조합 가능한 조건**: 메시지 필터와 여러 규칙을 설정할 수 있습니다. 채팅마다 처음 일치한 규칙이 '나열', '건너뛰기', 'LLM에 요약 맡기기'를 결정합니다. 조건은 '모두 일치/하나라도 일치'로 최대 2단계까지 조합할 수 있습니다. 예를 들어 메시지가 20개를 넘는 채팅만 LLM에 맡길 수 있습니다.
- **미리 계산**: 새 메시지 양식에서 결과를 미리 계산할 수 있습니다. 메시지를 읽기만 하며 전송하거나 LLM을 시작하지 않습니다.
- 새 메시지 일정이 보낸 목록은 다음 실행에서 다시 표시되지 않습니다. 두 계정이 받은 같은 그룹은 한 번만 표시됩니다. 한 번의 목록은 최대 49,000자이며, 초과하면 표시하지 않은 채팅 수와 메시지 수를 알려 줍니다.
- 알려진 제한: 목록을 보낸 후 Agent 작업을 만들지 못하면 해당 실행은 실패로 기록되고, 다음 실행에서 같은 메시지를 다시 표시합니다.
- **MCP 조회**: `query_target_messages_by_time`은 시작 시간만 지정하면 한 번에 모든 채팅을 조회합니다. 새 도구 `list_active_chats`는 시간 범위에 메시지가 있는 채팅과 개수를 보여 줍니다. 새 필터는 `excludeChatIds`, `direction`, `kinds`, `excludeKinds`입니다.
- **MCP 날짜 조회의 8시간 차이 수정**: 날짜만 있는 범위는 대만 시간의 하루로 처리합니다.
- **연결 오류 오판 수정**: 동기화 롱 폴링이 반환하는 410을 더 이상 연결 오류로 처리하지 않습니다.
- 이 앱은 계속 비공식 프로젝트이며 LINE 및 그 계열사와 제휴, 보증 또는 후원 관계가 없습니다.
