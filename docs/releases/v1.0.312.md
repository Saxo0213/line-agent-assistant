# v1.0.312 — changes since v1.0.311

## 繁體中文

Windows x64 版本。請從 **Assets** 下載 `LINE-Agent-Assistant-1.0.312-Setup-x64.exe`；`LINE-Agent-Assistant-1.0.312.zip` 為免安裝版。SHA-256 值列於 `SHA256SUMS.txt`。`latest.yml` 與 `.blockmap` 供 App 內自動更新使用；已安裝 v1.0.311 的使用者可直接在右下角提示選擇「更新」。

相較於上一個公開版本 [v1.0.311](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.311)：

- **Windows Agent worker 啟動修正**：修正安裝版 worker 靜態載入缺少的 `line-chrome` 造成的啟動問題；該問題可能影響 LINE 連線與重新啟動。
- **worker 範圍的 Chrome 載入**：`DESKTOPWIN` 正式 LINE worker 不載入 Chrome adapter、gate 或 `line-chrome`；選用 `CHROMEOS` worker 時才載入這些元件。打包內容包含該選項所需依賴。
- **隔離啟動 smoke**：新增隔離的 production-entry 啟動 smoke 檢查。
- 保留既有功能。

## English

Windows x64 release. Download `LINE-Agent-Assistant-1.0.312-Setup-x64.exe` under **Assets**; `LINE-Agent-Assistant-1.0.312.zip` is the portable build. SHA-256 hashes are in `SHA256SUMS.txt`. `latest.yml` and the `.blockmap` are used by the in-app updater; if v1.0.311 is installed, choose **Update** in the bottom-right prompt.

Changes since the previous public release, [v1.0.311](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.311):

- **Windows Agent worker startup fix:** fixes a packaged worker startup issue caused by a missing static `line-chrome` load. The issue could disrupt LINE connections and restarts.
- **Worker-scoped Chrome loading:** the `DESKTOPWIN` official LINE worker does not load the Chrome adapter, gate, or `line-chrome`; the `CHROMEOS` worker loads those components when selected. The package includes the dependency for that option.
- **Isolated startup smoke:** adds an isolated production-entry startup smoke check.
- Existing features are preserved.

## 日本語

Windows x64 版です。**Assets** から `LINE-Agent-Assistant-1.0.312-Setup-x64.exe` をダウンロードしてください。`LINE-Agent-Assistant-1.0.312.zip` はポータブル版です。SHA-256 は `SHA256SUMS.txt` に記載しています。`latest.yml` と `.blockmap` はアプリ内の自動更新で使用します。v1.0.311 をお使いの場合は、右下の通知で「更新」を選択できます。

前回の公開版 [v1.0.311](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.311) からの変更点：

- **Windows Agent worker の起動修正**：インストーラー版 worker が `line-chrome` を静的に読み込もうとして起動できない問題を修正しました。この問題により LINE の接続や再起動に支障が出ることがありました。
- **worker 単位の Chrome 読み込み**：`DESKTOPWIN` の公式 LINE worker は Chrome adapter、gate、`line-chrome` を読み込みません。`CHROMEOS` worker を選択した場合にのみ、これらのコンポーネントを読み込みます。この選択用にパッケージにも依存関係を含めています。
- **隔離された起動 smoke**：production-entry の起動を確認する隔離 smoke を追加しました。
- 既存機能は維持されます。

## 한국어

Windows x64 버전입니다. **Assets**에서 `LINE-Agent-Assistant-1.0.312-Setup-x64.exe`를 다운로드하세요. `LINE-Agent-Assistant-1.0.312.zip`은 포터블 버전입니다. SHA-256 값은 `SHA256SUMS.txt`에 있습니다. `latest.yml`과 `.blockmap`은 앱 내 자동 업데이트에 사용됩니다. v1.0.311을 사용 중이면 오른쪽 아래 알림에서 '업데이트'를 선택하면 됩니다.

이전 공개 버전 [v1.0.311](https://github.com/Saxo0213/line-agent-assistant/releases/tag/v1.0.311) 이후 변경 사항:

- **Windows Agent worker 시작 문제 수정**: 설치판 worker가 `line-chrome`을 정적으로 불러오다 시작되지 않는 문제를 수정했습니다. 이 문제는 LINE 연결과 재시작을 방해할 수 있었습니다.
- **worker 범위의 Chrome 로드**: `DESKTOPWIN` 공식 LINE worker는 Chrome adapter, gate 또는 `line-chrome`을 불러오지 않습니다. `CHROMEOS` worker를 선택한 경우에만 이 구성 요소들을 불러옵니다. 해당 선택 기능을 위해 패키지에 의존성도 포함합니다.
- **격리된 시작 smoke**: production-entry 시작을 확인하는 격리 smoke를 추가했습니다.
- 기존 기능을 유지합니다.
