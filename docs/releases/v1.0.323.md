# v1.0.323 — changes since v1.0.319

## 繁體中文

Windows x64 版本。可透過 App「檢查更新」安裝；手動安裝檔與免安裝版請見 GitHub v1.0.323 Release。

- **Claude Desktop 可完整等候 LINE 傳送：** 外部 MCP stdio bridge 對 `send_to_target` 最多等候 610 秒，不再於 10 秒中斷傳送；傳送進行中，其他查詢與排程工具仍可回應。
- **訊息轉發帶傳送者名稱：** 轉發文字以 `名稱: 原文` 開頭，名稱與聊天畫面相同（暱稱優先）；只有圖片或檔案的訊息會先傳一則 `名稱:`。
- **新訊息排程不再顯示「未知」：** 同一群組由多個帳號保存時，清單會從其他帳號補上群組名稱與傳送者名稱。
- **Agent 狀態圖示不互相覆蓋：** 同一聊天室連續多則訊息時，前一則的完成／失敗圖示與後一則的排隊圖示都會保留。

## English

Windows x64 release. Install through **Check for updates** in the app; the installer and portable build are available from the GitHub v1.0.323 release.

- **Claude Desktop waits for LINE sends:** The external MCP stdio bridge waits up to 610 seconds for `send_to_target` instead of aborting after 10 seconds. Other queries and schedule tools still respond while a send runs.
- **Forwarded messages show the sender:** Forwarded text starts with `name: original text`, using the same name as the chat view (nickname first). A message with only images or files first sends `name:`.
- **No more "unknown" in new-message schedules:** When several accounts store the same group, the list fills the group title and sender names from the other copy.
- **Agent status icons no longer overwrite each other:** With several messages in a row in one chat, the done/failed icon of the earlier message and the queued icon of the later one both stay.

## 日本語

Windows x64 版です。アプリの「更新を確認」から更新できます。インストーラーとポータブル版は GitHub v1.0.323 リリースから入手できます。

- **Claude Desktop が LINE 送信を最後まで待機：** 外部 MCP stdio bridge は `send_to_target` を最大 610 秒待ち、10 秒で中断しなくなりました。送信中も他の検索やスケジュールツールは応答します。
- **転送メッセージに送信者名を表示：** 転送テキストは `名前: 本文` で始まり、名前はチャット画面と同じ（ニックネーム優先）です。画像やファイルだけのメッセージは先に `名前:` を送ります。
- **新着メッセージのスケジュールで「不明」を解消：** 同じグループを複数のアカウントが保存している場合、一覧は別のアカウントからグループ名と送信者名を補います。
- **Agent ステータスアイコンが上書きされない：** 同じチャットで連続して複数のメッセージが届いても、前のメッセージの完了／失敗アイコンと次のメッセージの待機アイコンがどちらも残ります。

## 한국어

Windows x64 버전입니다. 앱의 '업데이트 확인'으로 설치할 수 있습니다. 설치 파일과 포터블 빌드는 GitHub v1.0.323 릴리스에서 받을 수 있습니다.

- **Claude Desktop이 LINE 전송을 끝까지 대기:** 외부 MCP stdio bridge가 `send_to_target`을 최대 610초 기다리며 10초에 중단하지 않습니다. 전송 중에도 다른 조회와 예약 도구가 응답합니다.
- **전달 메시지에 발신자 이름 표시:** 전달 텍스트가 `이름: 원문`으로 시작하며, 이름은 채팅 화면과 같습니다(닉네임 우선). 이미지나 파일만 있는 메시지는 먼저 `이름:`을 보냅니다.
- **새 메시지 예약에서 '알 수 없음' 해소:** 여러 계정이 같은 그룹을 저장하면 목록이 다른 계정에서 그룹 이름과 발신자 이름을 채웁니다.
- **Agent 상태 아이콘이 서로 덮어쓰지 않음:** 한 채팅에서 여러 메시지가 연속으로 와도 앞 메시지의 완료/실패 아이콘과 다음 메시지의 대기 아이콘이 모두 유지됩니다.
